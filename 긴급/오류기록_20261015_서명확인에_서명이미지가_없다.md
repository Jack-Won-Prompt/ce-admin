# 서명 동의 완료인데 「저장된 서명 이미지가 없습니다」 (2026-10-15)

## 신고 내용

(E)정용순 님은 화면에 **서명 동의 완료**로 표시되는데, `서명확인` 을 누르면 팝업에
「저장된 서명 이미지가 없습니다」가 표시되고, 왼쪽 서류 목록에도 위임장 이미지가
보이지 않는다.

```
위임동의 서명 확인
   서명자      정용순
   서명한 전화번호  010-6480-0866
   서명 일시    2026-10-08 12:15:20
   ⓘ 저장된 서명 이미지가 없습니다.
```

## 확인 결과 — 데이터 손실이 아니다

운영 데이터를 직접 조회했다.

| 확인 항목 | 결과 |
|---|---|
| 거래처 | #10483 (E)정용순 · 010-6480-0866 |
| 전자 동의 기록(`prescription_consents`) | **없음** |
| 위드웍스 위임 서명(`delegation_signs` #1607) | 발송만 되고 미서명 (`status=sent`, `agree_delegation=0`) |
| 첨부 위임장 | **있음** — `정용순님 위임장 수정본.jpg` 170KB, 2026-10-08 12:15:20 업로드 |
| 파일 실재 여부 | `disk(public)` 에 존재 확인 |

즉 이 건은 **전자 서명이 아니라 종이 위임장을 촬영해 업로드한 건**이다. 전자 서명
이미지가 없는 것이 정상이며, 서명 동의 완료 표시도 규정대로다
(`DelegationGate::signed` 는 서면 위임장을 승인 근거로 인정한다).

팝업의 서명 일시 `2026-10-08 12:15:20` 은 전자 서명 시각이 아니라 **파일 업로드
시각**이다.

## 위임장이 왼쪽 목록에 보이지 않은 이유

위임장 파일 3건은 **2026-07-10 처방전**에 첨부되어 있고, 현재 열린 처방전은
2026-10-12 건이다.

```
처방전 id 46859 · WW-ADD0047611 · 2026-07-10 · 첨부 3건  ← 위임장 3장
처방전 id 84812 · RX-20261012-089 · 2026-10-12 · 첨부 2건  ← 거래명세서, 신분증 (현재 화면)
```

`DelegationGate::서면위임장()` 은 **거래처 단위**로 조회하므로 승인 판정에는 문제가
없으나, 화면의 서류 목록은 **해당 처방전의 첨부만** 표시한다. 따라서 승인은 되는데
서류는 보이지 않는 상태가 된다.

## 조치

서명 확인 팝업에서 종이 위임장 건임을 명시하고, 해당 파일을 바로 열 수 있도록 했다.

서버(`ConsentController::statusCheck`)가 다음 항목을 추가로 반환한다.

```
rx_number   첨부된 처방전 번호
file_url    파일 열람 주소
file_name   업로드된 파일명
```

처방전 첨부(`paper`)와 거래처 서류함(`patient_paper`) 두 경우 모두 적용했다.

화면 표시 결과(운영 데이터로 검증).

```
서면 위임장(업로드)입니다. 전자 서명이 아니므로 서명 이미지가 없습니다.
처방전 WW-ADD0047611 에 첨부되어 있습니다.
[ 정용순님 위임장 수정본.jpg ]  ← 클릭 시 새 창으로 열람
```

커밋 `1601324e`. 운영 반영 완료.

## 검토 필요 사항

위임장이 지난 처방전에 첨부된 건은 현재 화면의 서류 목록에 표시되지 않는다. 서류
목록에 **거래처의 위임장을 함께 표시**하는 방안을 검토할 수 있으나, 표시 범위가
처방전 단위에서 거래처 단위로 바뀌는 변경이므로 별도 지시 후 진행한다.
