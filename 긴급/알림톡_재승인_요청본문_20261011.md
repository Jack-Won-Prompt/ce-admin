## 1. 왜 바꾸어야 하나

승인된 본문에 **「30분 유효」가 고정 글귀로 박혀** 있는데, 실제 서명 링크는
**보낸 날 23시 30분까지** 열려 있습니다(2026-10-01 지시로 바뀜).

| | |
|---|---|
| 실제 만료 | 보낸 날 **23시 30분** (`DelegationSignController::만료시각`) |
| 글에 적히는 말 | **「30분 유효」** |
| 「30분 유효」로 나간 글 | **750건** (알림톡 747 · 문자 3 · 2026-10-01 이후) |
| 「23시 30분」으로 나간 글 | **0건** |

**우리 코드에는 「30분 유효」라는 글자가 없습니다.** 카카오 승인 본문과, 그것을 그대로
베껴 담은 메시지 유형의 본문에만 있습니다. 그래서 코드로는 고칠 수 없고 **재승인이
필요합니다.**

환자는 30분이 지나면 링크가 닫힌 줄 알고 열어 보지 않습니다. 실제로는 그날 23시 30분까지
열려 있습니다.

## 2. 제출할 본문

바꾸는 것은 **한 줄뿐**입니다. 나머지는 승인된 글 그대로입니다.

### 지금 (승인본)

```
[콜로플라스트] 전자서명 요청

#{이름}님, 
개인정보 수집,이용 동의 및 
요양비 청구 위임에 대한, 
전자서명 요청입니다.

서명 링크(30분 유효):
#{링크}

콜로플라스트 케어(Care)
- TEL 1588-7866(연결 1번)
- TEL 02-2078-6866(연결 1번)
- 상담시간:평일 오전 9시~오후 6시
```

### 바꿀 본문

```
[콜로플라스트] 전자서명 요청

#{이름}님, 
개인정보 수집,이용 동의 및 
요양비 청구 위임에 대한, 
전자서명 요청입니다.

서명 링크(#{만료}까지):
#{링크}

콜로플라스트 케어(Care)
- TEL 1588-7866(연결 1번)
- TEL 02-2078-6866(연결 1번)
- 상담시간:평일 오전 9시~오후 6시
```

**바뀐 곳** — `서명 링크(30분 유효):` → `서명 링크(#{만료}까지):`

### `#{만료}` 에 들어가는 값

| 보낸 때 | 들어가는 말 | 나가는 줄 |
|---|---|---|
| 오전 9시 | `오늘 23시 30분` | 서명 링크(오늘 23시 30분까지): |
| 밤 23시 40분 | `내일 23시 30분` | 서명 링크(내일 23시 30분까지): |

24시로 적습니다 — 「11시 30분」으로 적으면 환자가 오전으로 읽습니다.
값을 짓는 자리는 `DelegationSignController::만료말()` 한 곳입니다.

**변수로 두면 유효 시간을 다시 바꿀 때 재승인이 필요 없습니다.** 지금처럼 글자로 박아
두면 바뀔 때마다 심사를 다시 받아야 합니다.

## 3. 코드 쪽은 이미 되어 있습니다

보내는 두 자리 모두 `#{만료}` 를 이미 넘기고 있습니다.

| 자리 | 넘기는 값 |
|---|---|
| `PrescriptionController` 5965줄 (주문 등록의 서명 링크) | `#{만료}` · `#{유효분}` · `#{링크}` · `#{고객명}` |
| `DelegationSignController` 823줄 (위임장 서명 명단) | 같음 |

승인이 나면 바꿀 것은 **두 값뿐**입니다.

1. 메시지 유형 `delegation_sign` 의 **팝빌 템플릿코드**를 새 코드로
2. 같은 유형의 **본문**을 위 새 본문으로 (한 글자도 다르면 팝빌이 630 「내용과 템플릿이
   일치하지 않음」으로 되돌립니다)

## 4. 심사 중에는

옛 템플릿이 그대로 살아 있으므로 발송은 멈추지 않습니다. 승인이 난 뒤에 위 두 값을
바꾸면 그때부터 새 글로 나갑니다.

**임시로 글을 고치는 길은 권하지 않습니다.** `#{링크}` 값은 자유 글이라 거기에 만료
시각을 덧붙일 수는 있으나(2026-10-10 실전송으로 확인), 바로 윗줄의 「30분 유효」가
그대로 남아 두 말이 서로 어긋납니다.
