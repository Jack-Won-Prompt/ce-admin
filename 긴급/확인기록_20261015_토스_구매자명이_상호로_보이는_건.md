## 답 — **이미 승인된 건은 바꿀 수 없다. 앞으로 것은 벌써 환자명이다.**

## 왜 그렇게 찍혔나

2026-10-12 에 **가상계좌 예금주를 상호로 바꾸라**는 지시가 있었다(`db3eda42`). 환자
이름을 보내면 「내가 나에게 보내나」로 읽혀 입금을 망설인다는 까닭이었다.

그런데 그 값을 짓는 자리가 **결제 화면 안에만** 있어, 한 값이 **모든 결제수단**에
실려 나갔다. 가상계좌의 예금주뿐 아니라 **카드ㆍ간편결제의 구매자명**까지 상호가 됐다.

2026-10-13 에 그 지시를 되돌렸다. 고치려던 것은 사실 이름에 붙은 동명이인 꼬리
(홍영철**A**)였고, 그것은 `Patient::실명` 이 떼므로 상호로 바꿀 까닭이 없었다.
짓는 자리도 `App\Support\PayNames` 한 곳으로 모았다.

```
상호로 나간 때 : 2026-10-12 14:25 ~ 2026-10-13 16:59
   우리 표(toss_payments)에 담긴 가상계좌 : 43건 (완료 39 · 입금대기 4)
   카드ㆍ간편결제 : 우리 표에 그 값을 담지 않아 셀 수 없다 — 토스 대시보드로만 보인다
```

## 바꿀 수 있나 — **우리 쪽에서는 없다**

토스페이먼츠 코어 API 에 **결제 정보를 고치는 자리가 없다.** 승인ㆍ취소ㆍ조회뿐이다.

```
POST /v1/payments/confirm            승인
GET  /v1/payments/{paymentKey}       조회
POST /v1/payments/{paymentKey}/cancel 취소
POST /v1/virtual-accounts            가상계좌 발급
…
```

`PATCH`ㆍ`PUT` 이 하나도 없고, 승인된 결제 객체에 `customerName` 을 되쓰는 길이 없다.
가상계좌 예금주도 **발급 요청에만** 넣는 값이다.

**대시보드에서 사람이 고칠 수 있는지는 우리가 알 수 없다.** 토스에 물어야 한다
(1544-7772 · support@tosspayments.com). 물어보실 거면 이렇게 적으시면 된다.

> 2026-10-12~13 에 발생한 결제 건의 구매자명(가상계좌 예금주)이 상호로 등록되었습니다.
> 승인이 끝난 건의 구매자명을 환자 이름으로 정정할 수 있습니까? 가능하다면 절차를

## 지금은 제대로 나가고 있다

```
2026-10-15 CARD            보낸이름[최재웅]  환자 (E)최재웅
2026-10-15 VIRTUAL_ACCOUNT 보낸이름[박백원]  환자 (E)박백원
지금 코드가 지으면 — (E)김태훈B → 카드 [김태훈] · 가상계좌 [김태훈]
```

`(E)` 와 동명이인 꼬리를 떼고 환자 실명으로 나간다. 샌드박스에서 결제창을 직접 열어
**토스 화면에 「김선미」로 찍히는 것까지 눈으로 보았다**(2026-10-15 바탕 시험).

**고객이 받는 증빙은 처음부터 멀쩡했다.** 우리가 그리는 카드매출전표에는 구매자가
「박예서」로 찍힌다 — 상호로 보이는 것은 **토스 대시보드의 조회 화면**뿐이다.

## 보다가 찾은 것 하나 — 우리 표에 `(E)` 가 담기고 있었다

```
toss_payments         CARD  [(E)이도] · [(E)김보민] · [(E)서경덕]
toss_payment_requests CARD  [송춘덕]  · [최재웅]   · [강종희]     ← 보낸 값은 깨끗
```

구매자명을 적는 자리가 이랬다.

```php
'customer_name' => $va['customerName'] ?? ($link->order?->patient?->name),
```

가상계좌는 토스가 돌려준 예금주를 쓰는데(그것이 정본이다), **카드는 토스 응답에 그
칸이 없어** 환자 이름 원본으로 떨어졌다. 거기에는 `(E)` 와 꼬리가 붙어 있다.

**토스에 간 값은 깨끗했다** — 보낸 기록(`toss_payment_requests`)이 그것을 보인다.
우리 표에만 어긋난 값이 담겼다. 그래도 이 칸을 읽어 밖으로 내보내는 자리가 생기면
그대로 샌다. 카드일 때도 `PayNames` 가 짓는 값을 적게 고쳤다(`32a2bd99`).
