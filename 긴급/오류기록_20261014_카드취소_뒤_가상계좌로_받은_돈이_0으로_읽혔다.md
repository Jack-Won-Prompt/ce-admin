# 카드 취소 뒤 가상계좌로 받았더니 받은 돈이 0으로 읽혔다

- 날짜 : 2026-10-14
- 찾은 자리 : 운영 점검(13:25) — 「증빙은 나갔는데 받은 돈이 0인 건 1건」
- 올린 것 : `7b5df7f6`

## 무슨 일이 있었나

(E)김대한 님 · 주문 `EUD202610081716351` · 81,000원

```
10-14 08:53  카드 결제 링크 발송
10-14 10:47  가상계좌로 바꿔 발급
10-14 10:48  **카드 결제 취소 웹훅** 도착 → 결제 줄에 취소액 81,000원이 적힘
10-14 11:31  가상계좌 링크 발송
10-14 12:31  **81,000원 입금 완료**
10-14 12:31  현금영수증 K00024389 · 세금계산서 2026101441000203000010d8 ·
             위드웍스 확정 S2610140026 · 거래명세서 · 결제 완료 안내까지 모두 나감
```

그런데 장부는 **「받은 돈 0원」** 이었습니다.

```
우리  : DONE · 결제 81,000원 · **취소액 81,000원**
토스  : DONE · 총액 81,000원 · **남은 금액 81,000원 · 취소 없음**
```

`Order::받은금액()` 이 「받은 돈 − 취소액」을 셈하므로 81,000 − 81,000 = 0 이 되었습니다.
정산ㆍ미수가 보는 값이라 **받은 돈이 장부에서 사라진 것**입니다.

## 왜 그랬나

`toss_payments` 는 **한 주문에 한 줄**입니다. 수단을 바꿔 다시 받으면 같은 줄을 덮어씁니다.
그때 **앞 결제의 취소 자취를 지워야** 합니다.

결제 줄을 세우는 자리는 둘인데 한쪽만 지우고 있었습니다.

| 자리 | 취소 자취를 지우는가 |
|---|---|
| `VirtualAccountService::주문결제줄()` | 지운다 (2026-09-23 무한 테스트 CASE 6 에서 넣음) |
| `VirtualAccountService::issueVirtualAccount()` | **지우지 않았다** ← 이번 건 |

가상계좌를 발급하는 자리는 `TossPayment::updateOrCreate` 로 열 칸만 쓰고
`cancel_amount`ㆍ`cancel_reason`ㆍ`canceled_at` 는 건드리지 않았습니다.

**같은 일을 하는 자리가 둘이고 한쪽만 고친** 모양입니다 — 어제 `OrderSync` 에서 겪은 것과
같습니다.

## 막은 것

`issueVirtualAccount()` 가 **결제키가 달라졌을 때** 앞 결제의 취소 자취와 입금 시각을
지우도록 했습니다. 같은 키로 다시 들어오는 일이 있어(돌아오는 화면 새로고침) 그때는
지우지 않습니다 — 부분취소한 금액이 없던 일이 되기 때문입니다.

## 바로잡은 것

토스에 다시 물어 **취소가 없음을 확인하고서만** 지웠습니다.

```
바꾸기 앞 : 받은 돈 0원 · 취소액 81,000원
바꾼 뒤   : 받은 돈 81,000원 · 취소액 0원

DONE 인데 취소액이 적힌 줄 : 1건 → 0건
```

주문 활동 이력에 왜 그랬는지와 근거를 적었습니다.

## 몇 건이었나

전수로 보았습니다.

```
결제가 DONE 인데 취소액이 적힌 줄        1건  (이 건뿐)
   토스에 취소가 없고 접수도 없는 것     1건
   실제로 취소된 것                      0건
결제가 DONE 인데 받은 돈이 0인 주문      1건  (같은 건)
```

**이 한 건뿐입니다.**
