# 소스를 고쳐도 **이미 저장된 세금계산서**는 그대로였다

- 날짜 : 2026-10-15
- 알린 이 : 운영 담당자 — 「운영에서 기존 세금계산서 주민등록번호 보이고 주소에 주소
  이외 값 제거가 아직 안 되어 있음」 · 이어서 「10월 1일부터 이후 증빙 생성건 모두
  반영되어야 함」

## 내가 놓친 것

종이를 그리는 자리(`TaxInvoiceForm::parties`)를 고치고 **그리기를 불러** 확인했다.
그것만 보고 「다 되었다」고 보고했다.

그런데 **담당자가 화면에서 내려받는 것은 그때 그때 그리는 종이가 아니다.** 발행하는
순간에 한 번 그려 파일로 담아 두고, 화면은 그 파일을 가리킨다.

```php
// OrderController::issueTaxInvoice
$pdfBytes = $this->buildTaxInvoicePdf($order);
$pdfPath  = 'tax_invoices/' . $order->id . '/' . $pdfName;
Storage::put($pdfPath, $pdfBytes);
PrescriptionDocument::한줄만([... 'type' => 'tax_invoice', 'file_path' => $pdfPath], ...);
```

그러니 **소스를 고쳐도 옛 파일은 발행 당시 모습 그대로**다. 새로 발행하는 것만 바뀐다.

**「고쳤다」를 확인할 때 사람이 실제로 여는 길로 확인하지 않았다.** 그리기를 직접 불러
본 것은 코드가 맞는지를 본 것이지, 담당자가 받는 종이를 본 것이 아니다.

## 그래서 한 일 — 346개를 다시 그렸다

```
prescription_documents (type=tax_invoice) · 10/1 이후   346개
   다시 그렸다           346개
   건너뛴 것               0개
   탈이 난 것              0개
```

파일 자리와 이름은 그대로 두고 내용만 덮었다 — 화면의 링크가 그 자리를 가리킨다.
발행 상태가 `issued` 인 건만 손댔다.

### 전수로 다시 열어 보았다

꼴로 어림잡지 않고 **건별로 맞춰** 보았다 — 그 건의 원래 주소에 있던 전화번호가
아직 종이에 있는지, 신고명에 있던 꼬리가 종이에 있는지.

```
① 등록번호가 아직 가려진 것     0건
   13자리를 아예 못 찾은 것     0건
② 이름 꼬리가 남은 것           0건
③ 원래 있던 전화번호가 남은 것  0건
   (E) 가 남은 것                0건
   주소가 종이에 안 보이는 것    0건
```

## 파일 **이름**에도 꼬리가 있었다

종이 안만 보고 이름을 보지 않았다.

```
세금계산서_이영주A_EUD202610010949491.pdf   ← 공단에 이 이름으로 간다
```

37개가 그랬다. 이름을 옮기고 표의 자리ㆍ이름을 함께 고쳤다 — 둘이 어긋나면 화면에서
열리지 않는다.

```
옮겼다 37개 · 그대로 둔 것 309개 · 탈 0개
확인 : 파일이 제자리에 346개 · 이름에 꼬리 0개 · 표와 자리가 어긋난 것 0개
       창고에 꼬리 붙은 파일이 남아 있나 0개
```

앞으로 발행하는 것도 실명으로 담기게 소스를 고쳤다(`0c5e88f0`) — 저장할 때와
내려받을 때 두 자리다.

## 손대지 않은 것 하나 — 발행되지 않은 건의 종이

```
prescription_attachments #11770
   세금계산서_이완영_EUD202610121352451.pdf
   주문 EUD202610121352451 · 발행상태 not_issued · 발행시각 없음
```

**발행하지 않은 주문에 세금계산서 종이가 붙어 있다.** 다시 그리면 발행하지도 않은 건의
증빙을 만드는 셈이라 건드리지 않았다. 자동발행이 붙임만 만들고 발행에 실패한 자취로
보이는데, 단정하지 않는다 — 따로 보아야 한다.

## 다음부터

고친 것을 확인할 때 **사람이 실제로 여는 길**로 확인한다. 함수를 불러 보는 것은 코드가
맞는지를 보는 것이지, 쓰는 사람이 받는 것을 보는 것이 아니다. 특히 **한 번 만들어 담아
두는 것**(PDF·엑셀·첨부)은 소스를 고쳐도 옛것이 그대로 남는다.
