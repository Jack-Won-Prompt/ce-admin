# 알림톡 버튼 URL에 변수를 쓸 수 있는가

- 날짜 : 2026-10-14
- 물음 : 「알림톡 버튼 URL에 변수 설정이 가능한지?」
- 대상 : 템플릿 `026100000981` (처방) 전자서명 요청 261014 · 심사중
  버튼 「개인정보동의 및 청구위임」 → `https://75.2.99.52/consent/#{버튼1}`

## 답 — 됩니다. 다만 **우리 코드를 고쳐야 나갑니다**

### 보내는 쪽은 이미 할 수 있다

팝빌 SDK(`PopbillKakao.php`)가 보낼 때 단추를 함께 싣습니다.

```php
if (!$this->isNullOrEmpty($Btns)) $Request['btns'] = $Btns;

class KakaoButton {
    public $n;   // 단추 이름
    public $t;   // 종류 (WL = 웹링크)
    public $u1;  // 모바일 URL
    public $u2;  // PC URL
    public $tg;  // 타깃
}
```

우리 쪽에도 그 칸이 **이미 있습니다** — `App\Services\Popbill\KakaoReceiver::$btns`,
주석에 「버튼 목록 — 비워 두면 템플릿에 등록된 버튼이 그대로 나간다」라고 적혀 있습니다.

### 그런데 **아무도 채우지 않는다**

```
app/ 전체에서 ->btns 를 채우는 자리 : 없음
```

지금은 템플릿에 박힌 단추가 그대로 나갑니다. 등록된 알림톡 템플릿 22개를 보면
단추가 있는 것은 둘뿐이고 **모두 고정 주소**입니다.

```
026090001920 재등록 신청 안내  → nhis.or.kr … (고정)
026090001914 (처방외)개인정보동의 → https://www.ceadmin.co.kr/privacy (고정)
```

**변수를 쓴 단추는 이번이 처음입니다.**

### 그래서 지금 그대로 심사를 통과하면

템플릿의 `#{버튼1}` 자리가 **빈 채로** 나가거나 글자 그대로 나갑니다. 환자가 누르면
`https://75.2.99.52/consent/` 로 가서 **어느 건인지 모르는 화면**이 열립니다.

## 고칠 자리

지금 서명 링크는 **글 안**에 통째로 들어갑니다.

```php
$url = $baseUrl . '/consent/' . $token;      // PrescriptionController:6410
$message = MessageTemplate::문구('consent_sign', ['#{링크}' => $url, …]);
```

단추로 옮기려면 보낼 때 `btns` 를 채워야 합니다 — 토큰만 넣으면 됩니다.

```php
$받을이->btns = [[
    'n'  => '개인정보동의 및 청구위임',
    't'  => 'WL',
    'u1' => $url,     // 또는 토큰만: 템플릿이 앞부분을 들고 있으면 #{버튼1} = $token
    'u2' => $url,
]];
```

**어느 쪽인지는 템플릿이 정합니다.**

- 템플릿 주소가 `https://75.2.99.52/consent/#{버튼1}` 이면 → `#{버튼1}` 에 **토큰만** 넣습니다.
- 템플릿 주소를 통째로 변수로 두면 → **전체 주소**를 넣습니다.

지금 올라간 템플릿은 앞의 꼴이므로 **토큰만** 넘기면 됩니다.

## 함께 봐야 할 것 — 주소가 **IP** 입니다

```
https://75.2.99.52/consent/#{버튼1}
```

도메인이 아니라 **날 IP** 입니다. 두 가지가 걱정됩니다.

1. **심사** — 카카오가 IP 주소 링크를 받아 줄지 알 수 없습니다. 지금 심사중이라 결과를
   봐야 합니다.
2. **인증서** — IP 로 여는 https 는 인증서 경고가 날 수 있습니다. 환자 폰에서 경고가
   뜨면 서명을 포기합니다.

운영 도메인(`mycolo.co.kr`)으로 바꾸는 편이 안전합니다. 다만 그 도메인이 지금 이
서버로 열려 있는지는 따로 확인해야 합니다 — 제가 오늘 `mycolo.co.kr` 로 열었을 때는
이름이 풀리지 않았습니다(`ERR_NAME_NOT_RESOLVED`).

## 정리

| 물음 | 답 |
|---|---|
| 버튼 URL에 변수를 쓸 수 있나 | **쓸 수 있다**. 팝빌이 보낼 때 단추를 싣는 길을 연다 |
| 지금 그대로 되나 | **안 된다**. 우리 코드가 `btns` 를 채우지 않는다 |
| 무엇을 고치나 | 알림톡을 보낼 때 `btns` 에 이름ㆍ종류(WL)ㆍ모바일 URLㆍPC URL 을 담는다 |
| 템플릿에는 무엇을 넣나 | 앞부분을 템플릿이 들고 있으므로 `#{버튼1}` 에는 **토큰만** |
| 더 볼 것 | 주소가 날 IP 다 — 심사와 인증서를 확인해야 한다 |

심사가 끝나 템플릿 코드가 확정되면 그때 코드를 고치겠습니다. 지시 주십시오.
