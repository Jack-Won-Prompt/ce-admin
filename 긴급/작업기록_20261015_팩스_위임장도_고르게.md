# 팩스의 요양비위임장도 고를 수 있게 했다

- 날짜 : 2026-10-15
- 지시 : 운영 담당자 — 「팩스 전송 시 모든 서류는 선택 가능하게 ⇒ 요양비위임장
  (생성 서류에 있음 — 그대로 함께 나갑니다)는 자동 아닌 선택 가능하게」

## 여태 어땠나

그 줄은 **고르는 칸이 없는 알림판**이었다.

```
📄 요양비위임장
   생성 서류에 있음 — 그대로 함께 나갑니다
```

보낼 때는 화면이 따로 박아 넣었다 — 담당자가 무엇을 하든 늘 실렸다.

```js
const docs      = faxGenDelegation ? ['delegation'] : [];
const docLabels = faxGenDelegation ? ['요양비위임장'] : [];
```

## 고친 것

그 줄을 **다른 생성 서류(세금계산서ㆍ현금영수증)와 같은 꼴**로 세운다.

```
☑ 요양비위임장  [생성 서류]
   서명받은 요양비위임장을 함께 보냅니다
```

공단 등록에 꼭 드는 서류라 **처음부터 골라 두되**, 끄면 실리지 않는다. 박아 넣던
자리를 걷어, 고른 칸을 거두는 자리에서 함께 담기게 했다.

쓰이지 않게 된 알림판 그리기도 걷었다 — 죽은 꼴이 남아 있으면 다음 사람이 어느
쪽이 도는지 헤맨다.

## 손대지 않은 것

- **서버**는 `documents` 에 `delegation` 을 이미 받아 처리한다(`collectFaxFiles`).
  검증 목록에도 들어 있다. 그대로 둔다.
- **자동 팩스**는 서버가 보낼 것을 스스로 정하므로 이 변경의 영향을 받지 않는다.

## 확인

이 화면은 전에 한 번 깨뜨린 적이 있어(단순 치환으로 줄바꿈이 들어갔다) 문법을 두 겹으로
보았다.

1. 바꾼 블록 넷을 떼어 `node --check` — 모두 이상 없음
2. **화면 전체의 `<script>` 를 뽑아** `node --check` — 네 블록 모두 통과

둘째 검사에서는 blade 지시문을 값으로 바꿔 JS 만 남긴다. `@if`ㆍ`@else` 양쪽 가지가
함께 남아 같은 이름이 두 번 선언되는 자국이 둘 생기는데, 그것은 **추출의 자국**이지
코드의 흠이 아니다(실제 렌더에서는 한쪽만 남는다). 그 둘을 걷으면 통과한다.

운영에 들어간 것도 파일로 확인했다.

```
state: 'doc', doc: 'delegation'   1곳
d.src === 'patient_doc'           1곳
'gen'                             0곳 (사라졌다)
```

**담당자가 화면을 새로 열어 확인해 주셔야 끝이다.**
