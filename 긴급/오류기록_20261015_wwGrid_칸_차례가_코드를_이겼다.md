# 코드에서 칸 차례를 바꿔도 화면에 보이지 않았다

- 날짜 : 2026-10-15
- 알린 이 : 운영 담당자 — 「모든 화면에서 wwGrid 항목 위치 조정했는데 계속 변경한
  위치에 없고 기존 위치에 있다」

## 까닭 — **남긴 차례가 코드를 이긴다**

wwGrid 는 머리줄을 끌어 옮긴 칸 차례를 브라우저(`localStorage`)에 남긴다.
그리고 화면을 세울 때 **남긴 것이 있으면 그것을 쓰고 코드를 보지 않는다.**

```js
_applySavedOrder() {
  const 남긴것 = this._loadOrder();
  if (!남긴것) return;          // ← 남긴 것이 있으면 그것이 이긴다
```

담당자가 끌어 둔 자리를 배포로 덮어버리지 않으려는 뜻이었다(2026-09-10).

**그런데 그 한 가지만으로 우리가 칸을 더하거나 자리를 바꿔도 보이지 않는다.**
한 번이라도 칸을 끌어 본 사람은 그 뒤로 코드가 어떻게 바뀌든 여태 차례만 본다.

10월에 칸을 여러 번 고쳤다.

```
1259e3ae  주문 목록ㆍ주문 관리에 요청한 항목을 세운다 (SR #193ㆍ#192)
5c129676  NB주민번호를 처방전 목록과 거래처 관리에도 세운다 (SR #171ㆍ#191)
c89a6263  주문 관리에 처방번호ㆍ금액 칸을 채운다
f830d9b4  처방전 목록에 「위임장」과 「주문 진행」을 세운다
```

그 가운데 **새로 더한 칸은 보인다** — 남긴 차례에 없는 칸은 「코드에서 누구 뒤였나」를
보고 끼워 넣기 때문이다. 하지만 **이미 있던 칸의 자리를 옮긴 것은 닿지 않는다.**
담당자에게는 「바꿔 달라 했는데 그대로다」로 보인다.

## 고친 것 — 코드 차례에 지문을 붙인다

코드에 적힌 칸 이름을 이은 글을 지문으로 함께 담는다.

```js
this._orderSig = this._codeOrder.join('|');

// 담을 때
localStorage.setItem(열쇠, JSON.stringify({ sig: this._orderSig, order: […] }));

// 읽을 때
if (Array.isArray(v)) return null;                 // 옛 꼴 — 버린다
if (!v || v.sig !== this._orderSig) return null;   // 코드가 바뀌었다 — 버린다
```

칸이 늘거나 줄거나 **자리가 바뀌면** 지문이 달라지고, 그때는 남긴 것을 버리고 코드를
따른다. 다시 끌어 두면 그것이 새 지문으로 담긴다.

### 한 번은 풀린다

이미 담긴 옛 꼴은 이름만 담은 배열이라 **지문이 없어 코드가 바뀌었는지 알 수 없다.**
한 번 버린다. 담당자가 끌어 둔 자리가 그때 풀리지만, 그러지 않으면 바꾼 차례가 영영
닿지 않는다.

**끌어 둔 자리는 다시 끌어 주셔야 한다.** 그 뒤로는 코드가 바뀔 때만 풀린다.

### 캐시는 걱정 없다

`@assetv` 가 파일 수정시각을 붙여 캐시를 무효로 만든다. 배포 뒤 새로고침하면 새
`wwGrid.js` 가 간다(운영에 들어간 것과 `Last-Modified` 갱신을 확인했다).

## 따로 남은 것 — **운영이 IP 둘로 열린다**

`localStorage` 는 **주소(origin)마다 따로**다. 그런데 운영은 도메인이 없고 IP 로 여는데,
그 IP 가 둘이다.

```
https://75.2.99.52      HTTP 200
https://76.223.51.164   HTTP 200     ← 같은 서버가 둘 다 답한다
APP_URL=https://75.2.99.52
nginx  server_name 75.2.99.52 76.223.51.164
```

한쪽에서 칸을 조정하고 다른 쪽으로 들어가면 **그 조정이 없는 것으로 보인다.** 브라우저가
다르거나 PC 가 다를 때도 마찬가지다 — 남기는 자리가 그 브라우저 안이기 때문이다.

이번 일의 원인은 위의 「지문」이지만, 이것도 같은 증상을 낸다. 담당자가 늘 같은 주소로
들어오는지 한 번 봐야 한다.

**근본으로 없애려면** 칸 설정을 사람마다 서버에 담아야 한다. 그러면 어느 주소ㆍ어느
PC 에서 들어와도 같다. 큰 일이라 지시를 받고 한다.
