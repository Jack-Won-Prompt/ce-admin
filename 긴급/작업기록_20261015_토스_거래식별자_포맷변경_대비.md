```

payment_links.payment_key              200자  ✓
order_returns.topup_payment_key        200자  ✓
```

새 식별자가 100자를 넘으면 **조용히 잘려** 결제를 되짚을 수 없게 됩니다. 돈이 걸린 표라
토스 문서의 최대 길이(200자)에 맞췄습니다.

```

```

### ㈏ 길이를 재는 잣대 하나

`DuplicatePaymentController` 의 `'payment_key' => ['required','string','max:100']` 를
**200** 으로 넓혔습니다.

아주 걷지는 않았습니다 — 담는 칸이 유한하므로 한도가 없으면 DB 가 터집니다. 토스가
문서에 적어 둔 최대 길이에 맞추고 칸도 같은 값으로 두어, 둘이 어긋나지 않게 했습니다.
