# 미성년 건은 보호자가 받고, 보호자 정보를 모두 받는다 · 동의서는 펼쳐 둔다

- 날짜 : 2026-10-15
- 지시 셋
  1. 「위임서명 링크에서 미성년자 경우, 보호자가 서명 메시지 받고」
  2. 「보호자정보 모든 항목은 필수」
  3. 「개인정보 동의서쪽을 클릭하면 자동으로 펼쳐지게」

## ① 미성년이면 보호자가 문자를 받는다

여태 보낼 번호를 **Main contact** 만 보고 정했다.

```php
$번호 = $this->main_contact === 'guardian' ? $this->guardian_phone : $this->phone;
```

미성년 건을 아이 번호로 보내면 그 링크는 **보호자 칸에서 멈춘다.** 아이가 제
휴대전화로 본인확인을 할 수도 없다. 미성년이면 Main contact 가 무엇으로 서 있든
보호자가 먼저다.

```php
$보호자쪽 = $this->미성년인가() || $this->main_contact === 'guardian';
$번호 = $보호자쪽 ? $this->guardian_phone : $this->phone;
```

미성년 판정은 `DelegationSign::미성년인가()` 가 이미 하고 있었다 — 주민번호로 가른다.

**보호자 번호가 비어 있으면 환자 번호로 물러나지 않는다.** 그러면 미성년에게 링크가
가고 어차피 보호자 칸에서 멈춘다. 보내지 않고 화면에서 ［수정］으로 채우게 한다
(2026-09-14 에 Main contact 를 그렇게 다룬 것과 같다).

못 보내는 까닭을 **그 건에 맞게** 적는다.

```
미성년자 건이라 보호자(법정대리인)에게 보냅니다.
보호자 전화번호가 없거나 형식이 올바르지 않습니다 — ［수정］에서 입력해 주십시오.
```

여태는 「환자 전화번호가 없습니다」라고 적혀, 담당자는 멀쩡한 환자 번호를 보며
무엇이 비었는지 찾지 못했다.

## ② 보호자 정보를 모두 필수로

| 칸 | 여태 | 이제 |
|---|---|---|
| 가입자ㆍ피부양자와의 관계 | 필수 | 그대로 |
| 법정대리인 또는 가족 성명 | 필수 | 그대로 |
| **보호자 전화번호** | **아예 재지 않았다** | 필수(9~11자리) |
| 법정대리인 또는 가족 생년월일 | 필수 | 그대로 |
| 보호자 서명 | 필수 | 그대로 |
| **법정대리인 또는 가족 신분증** | **한 번 묻고 지나갔다** | 필수 |

### 2026-09-09 지시를 되돌렸다

신분증은 그때 **일부러 막지 않았다.**

> 그 자리에 신분증이 없거나 사진이 흐려 못 올리는 사람이 있다. 그때 통째로 막히면
> 받아 둘 수 있었던 서명마저 못 받는다.

오늘 그 지시를 되돌린다. 반쪽으로 받아 두면 담당자가 다시 연락해 같은 일을 또 해야
하고, 미성년 건은 보호자 서류가 갖춰져야 공단에 낼 수 있다. **되돌린 것임을 여기 적어
둔다** — 신분증을 못 올려 서명 자체가 막히는 일이 생기면 이 자리를 다시 보아야 한다.

### 이미 받아 둔 신분증은 다시 청하지 않는다

이 화면은 **받아 둔 신분증을 다시 보여 주지 않는다.** 그래서 그것까지 막으면 이미 낸
사람이 또 올려야 한다. 받아 둔 것이 있으면 통과시킨다.

```js
const G_ID_ALREADY = @json((bool) ($consent->guardian_id_path ?? false));
function guardianIdOk() { return !!(gIdData || G_ID_ALREADY); }
```

### 화면과 서버 양쪽에서 막는다

화면만 막으면 화면을 거치지 않고 들어오는 요청이 샌다 — 서버에도 같은 빗장을 두었다.
화면이 여섯 칸을 모두 담아 보내고 있었으므로 보내는 쪽은 손대지 않았다.

## ③ 개인정보 동의서를 펼쳐 둔다

담당자가 「안에 추가로 동의할 것이 있는데 닫혀 있어 잘 보이지 않는다」고 알렸다.

다른 카드는 **읽어 보는 서식**이지만 이것은 **골라야 하는 칸**이다. 안에 동의 항목이
줄줄이 있는데 접혀 있어, 그런 것이 있는 줄도 모르고 지나쳤다. 해야 할 일이 든 칸은
열어 둔다.

함께, 카드의 **설명 줄을 눌러도** 펼쳐지게 했다. 머리 단추만 눌리고 바로 아래 설명
줄은 단추 밖이라, 거기를 눌러 본 사람은 닫힌 채로 지나쳤다.

열림은 클래스로 정하므로 마크업에 `open` 을 달면 속은 보이는데 머리 글자는 「펼치기」
그대로고 서식 틀도 불러오지 않는다. 그 둘을 화면이 뜰 때 한 번 맞춘다 — **마크업에
글자를 박으면 두 곳이 갈린다.**

## 짚어 둘 것

- `resources/views/consent/sign.blade.php` 는 **CRLF** 다. 줄끝을 맞추지 않으면 치환이
  조용히 빗나간다 — 오늘 그것 때문에 두 번 헛돌았다.
- 바꾼 뒤 화면 전체의 `<script>` 를 뽑아 `node --check` 로 보았다. 이상 없다.

## 아직 보지 못한 것

**사람이 실제로 눌러 본 확인은 담당자 몫이다.** 특히 미성년 건으로 링크를 한 번 보내
보시면 좋다 — 보호자 번호로 가는지, 보호자 정보를 다 채워야 넘어가는지.
