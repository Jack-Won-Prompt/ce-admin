# 가상계좌를 닫을 때 나던 오류 두 가지를 맡아서 처리한다 (2026-10-16 지시)

## 무엇이 있었나

10-16 하루 ERROR 2건이 모두 **가상계좌 재발급 과정**에서 났다.

```
08:42:14  403 FORBIDDEN_CONSECUTIVE_REQUEST   (E)조용관
09:56:22  403 NOT_CANCELABLE_PAYMENT          (E)이승준A
```

두 건 모두 **결과는 정상**이었다. 확인해 보니 옛 계좌는 전부 해지되었고 열린 채 남은
계좌는 없었다.

```
(E)조용관   최종 계좌 46521598418605 · 20,250원 · 기한 10-19 · 옛 링크 3건 모두 해지
(E)이승준A  최종 계좌 46521605418671 · 81,000원 · 기한 10-19 · 옛 링크 4건 모두 해지
```

처리되는 일이 오류로 쌓이면 진짜 오류가 묻힌다.

## 두 코드의 뜻

| 코드 | 상황 | 바른 처리 |
|---|---|---|
| `FORBIDDEN_CONSECUTIVE_REQUEST` | 같은 계좌를 잇따라 닫으려 했다 | 잠깐 쉬고 한 번 더 부른다 |
| `NOT_CANCELABLE_PAYMENT` | 이미 취소됐거나 **이미 입금됐다** | 저쪽에 다시 물어 **둘을 가른다** |

두 번째는 그냥 넘기면 안 된다. 「이미 취소됨」과 「이미 입금됨」은 결과가 전혀 다르다 —
입금된 계좌를 닫은 것으로 처리하면 받은 돈이 장부에서 사라진다.

## 고친 것

### ① 오류에 토스 코드를 담는다

여태 코드로 갈라야 할 때 메시지 글을 뜯어 보는 수밖에 없었다. 저쪽이 문구를 바꾸면
그대로 깨진다.

```php
class TossApiException extends \RuntimeException
{
    public function __construct(string $message = '', private string $토스코드 = '', int $http = 0)
    public function 토스코드(): string
}
```

`getCode()` 는 지금까지처럼 HTTP 상태를 돌려준다 — 그 값을 쓰던 자리가 그대로 선다.

### ② 부르는 쪽이 맡는 코드는 경고로 적는다

```php
$적을곳 = in_array($code, $맡아서처리할코드, true) ? 'warning' : 'error';
Log::$적을곳('[Toss] API 오류', [...]);
```

다른 자리에서 나는 오류는 그대로 ERROR 다.

### ③ 가상계좌 닫기가 두 경우를 스스로 처리한다

```
FORBIDDEN_CONSECUTIVE_REQUEST
   0.8초 쉬고 한 번만 더 부른다 → 성공하면 그대로 닫힌다

NOT_CANCELABLE_PAYMENT
   토스에 결제 상태를 다시 묻는다
      CANCELED · EXPIRED · ABORTED → 「이미 닫혀 있는 계좌였습니다」 (정상)
      DONE                         → 「이미 입금된 계좌라 닫을 수 없습니다 —
                                       환불로 처리해야 합니다」 (경고 기록)
      그 밖                        → 여태처럼 닫지 못한 것으로 돌려준다
```

## 시험

토스를 부르지 않는 길을 모두 돌려 확인했다.

```
오류가 코드를 담는가
   메시지   [NOT_CANCELABLE_PAYMENT] 취소 할 수 없는 결제 입니다.
   토스코드 NOT_CANCELABLE_PAYMENT
   getCode  403                      ← HTTP 상태 그대로
   코드 없이 만든 것 → 빈 글자

토스를 부르지 않는 길
   계좌 줄 없음   ok   닫을 가상계좌가 없습니다.
   이미 닫힌 줄   ok   이미 닫혀 있습니다.
   이미 입금된 줄 실패 이미 입금된 계좌는 닫을 수 없습니다 — 환불로 처리해야 합니다.
   카드 줄        ok   닫을 가상계좌가 없습니다.
```

저쪽을 부르는 두 길은 실제 상황이 생길 때 로그로 확인한다.
