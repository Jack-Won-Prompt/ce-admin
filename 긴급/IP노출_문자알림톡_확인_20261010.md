## 3. 알림톡 — 「전자서명하기」 글씨로 가릴 수 있나

### 가릴 수 있습니다. 다만 **템플릿을 고쳐야 합니다.**

카카오 알림톡의 **웹링크 버튼(WL)** 은 버튼 이름만 보이고 주소는 보이지 않습니다.
우리 템플릿 가운데 **이미 그렇게 쓰는 것이 둘 있습니다.**

| 템플릿 | 버튼 이름 | 버튼 주소 |
|---|---|---|
| `026090001914` (처방외)개인정보동의 | **개인정보 동의** | `https://www.ceadmin.co.kr/privacy` |
| `026090001920` 재등록 신청 안내 | 자가도뇨소모성재료 지원 / 건강보험공단 지사찾기 | 공단 주소 두 곳 |

문제의 `026090001915`(전자서명 · 747건)는 **버튼이 0개**이고 본문에 `#{링크}` 를 그대로 찍습니다.

```
[콜로플라스트] 전자서명 요청
…
서명 링크(30분 유효):
#{링크}          ← 여기에 https://75.2.99.52/consent/… 가 찍힌다
```

이것을 「전자서명하기」 버튼으로 옮기려면 **본문에서 `#{링크}` 를 빼고 WL 버튼을 다는**
템플릿 변경이 필요합니다.

### 보낼 쪽 코드는 이미 준비돼 있습니다

- 팝빌 SDK `SendATS` 는 요청 수준 `btns` 를 받습니다(`PopbillKakao.php:431` 열한째 인자).
- 우리 `KakaoReceiver` 도 건마다 `btns` 를 실어 보낼 수 있게 되어 있습니다
  (`app/Services/Popbill/KakaoReceiver.php:40`).
- **다만 우리 코드가 둘 다 쓰지 않습니다** — `KakaoService::sendAts()` 가 `btns` 를 넘기지
  않고, `btns` 를 채우는 자리도 없습니다. 한 줄이면 열립니다.

### 재심사 — 나누어 보아야 합니다

| 무엇을 바꾸나 | 재심사 |
|---|---|
| **`#{링크}` 에 담기는 값만 바꾸기** (IP → 도메인) | **필요 없습니다.** 변수 값이라 템플릿이 그대로입니다 |
| **버튼을 새로 달고 본문에서 링크를 빼기** | **템플릿 변경이므로 심사를 다시 받습니다** |

> **카카오·팝빌에 확인이 필요한 한 가지** — 버튼 주소를 **건마다 다르게**(서명 토큰이
> 매번 다릅니다) 보내려면, 템플릿 등록 때 버튼 주소에 변수 자리를 함께 승인받아야 하는지
> 입니다. 지금 우리 두 템플릿의 버튼은 **고정 주소**라 이 경우가 아닙니다.
> 고정 주소만 허용된다면 버튼으로는 토큰 링크를 보낼 수 없고, 2-단계(버튼 → 공통 입구 →
> 본인확인 뒤 건 찾기)로 바꾸어야 합니다.

## 4. 문자 — 글씨로 가릴 수 있나

### 가릴 수 없습니다.

문자(SMS·LMS)는 **글자만** 보냅니다. HTML 도 앵커도 없어서 「결제하기」라는 글씨 뒤에
주소를 숨길 수 없습니다. 휴대폰이 주소를 눌러지게 만들어 줄 뿐, **주소 문자열은 늘 보입니다.**

문자에서 IP 를 안 보이게 하는 길은 셋뿐입니다.

| 길 | 무엇을 하나 | 재심사 | 비고 |
|---|---|---|---|
| ① **주소를 도메인으로** | `75.2.99.52` → `mycolo.co.kr` 같은 이름 | 없음 | **주소는 여전히 보인다.** IP 만 안 보인다 |
| ② **알림톡으로 옮기기** | 결제 안내를 알림톡 + 버튼으로 | **필요** (새 템플릿) | 실패하면 문자로 떨어지므로 ①도 함께 해야 한다 |
| ③ RCS(브랜드 메시지) | 버튼이 되는 문자 | 별도 등록 | 지금 팝빌 연동 범위 밖 |

**지금 결제 안내(234건)는 문자로만 나갑니다.** 승인된 알림톡 「미결제(`026090002267`)」가
있는데 우리 유형에 붙어 있지 않습니다 — 다만 그 템플릿도 본문에 `#{링크}` 를 찍으므로,
그대로 쓰면 IP 가 보이는 것은 같습니다.

   없이 바뀐다** (지금 비어 있어 `APP_URL` 로 떨어지고 있습니다).
2. `/pay/` 는 `APP_URL` 하나만 보므로 같은 고리를 달아 준다 (작은 코드 변경 한 곳).
3. 전제 — 그 도메인이 **인증서와 함께 운영을 가리켜야** 합니다. `mycolo.co.kr` 전환과
   묶이는 일이고, 바꿀 때 밖에서 부르는 콜백 넷도 함께 다시 등록해야 합니다.

→ 이것만으로 **984건 전부에서 IP 가 사라집니다.** 주소 글자는 남습니다.

### 나. 재심사를 거쳐 (주소까지 안 보이게)

4. `026090001915` 전자서명 템플릿을 **본문에서 `#{링크}` 를 빼고 「전자서명하기」 WL 버튼**
   으로 다시 등록한다 → 747건이 글씨만 보이게 된다.
5. 결제 안내도 같은 꼴의 알림톡 템플릿(「결제하기」 버튼)을 새로 받아 옮긴다 → 234건.
6. 보낼 쪽은 `KakaoService::sendAts()` 에 `btns` 를 넘기도록 한 줄 열면 됩니다.

### 다. 먼저 물어야 할 것 (카카오·팝빌)

- 버튼 주소에 **변수**를 쓸 수 있는가(토큰이 매번 다름). 안 되면 4·5 번은 공통 입구 +
  본인확인 꼴로 다시 설계해야 합니다.
- 심사 기간과, 심사 중에도 옛 템플릿으로 계속 보낼 수 있는지.
