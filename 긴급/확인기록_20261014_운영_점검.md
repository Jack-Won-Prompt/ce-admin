
## 함께 찾은 것 — 큐 설정이 잘못되어 있습니다

```
.env   QUEUE_CONNECTION=file
config/queue.php 에 있는 연결 : sync · database · beanstalkd · sqs · redis · deferred · failover · background
                                 ← **file 은 없다**

Queue::connection() → The [file] queue connection has not been configured.
```

큐에 일을 넣는 자리가 불리면 **그 자리에서 터집니다.**

지금 넣는 자리는 하나뿐입니다 — `AgentHookController` 가 SR 이 들어올 때 부르는
`AgentWorkJob::dispatch()`. 그 길이 오늘까지 불린 적이 없어(`jobs` 0 · `failed_jobs` 0)
드러나지 않았을 뿐입니다.

`file` 이라는 이름은 아마 **파일 큐를 쓰려던 흔적**으로 보이나, 라라벨에는 그런 연결이
없습니다. `sync`(그 자리에서 바로 처리) 또는 `database`(표에 쌓고 일꾼이 처리) 가운데
하나여야 합니다.

- `sync` — 일꾼이 필요 없습니다. SR 처리가 웹 요청 안에서 끝나므로 응답이 그만큼 늦습니다.
- `database` — 표에 쌓고 `queue:work` 일꾼이 처리합니다. **일꾼을 세워 두어야 합니다**
  (지금 `agent-queue` 서비스는 이 서버에 없습니다).

**손대지 않았습니다.** 운영 설정이라 지시를 받고 바꾸겠습니다.
