# 기초 건의 서명이 다음 구매에도 이어지는가

- 날짜 : 2026-10-15
- 물음 : 운영 담당자 — 「기초이신 분들은 앞으로 계속 구매시마다 **동일 서명**에 대해
  요양비 지급청구서에 표시되어야 해서 확인 요청」
- 답 : **이어집니다. 장치가 이미 있고 실제로 일하고 있습니다.**

## 어떻게 이어지나

청구서에 얹는 서명은 `DelegationGate::쓸서명()` 이 고른다. 네 길을 차례로 본다.

```
① 이건서명        이 처방전에서 받은 서명
② 지난서명        같은 거래처의 다른 처방전 서명 — **기간이 남아 있으면**
③ 옮겨온서명동의  운영 자료에서 옮겨 담은 것
④ 공개동의서서명  /privacy 링크에서 받은 것
```

②가 바로 물으신 자리다. **새로 사도 지난 서명을 그대로 쓴다.**

기간은 **서명한 날로부터 5년**이다. 거래처에 건보위임동의 종료일(`nhis_agree_end`)이
적혀 있으면 그 날이 먼저다.

## 실제로 그렇게 되고 있다 (10/1 이후 기초 67건)

```
서명이 있다  46건
   이 건에서 받은 것          41건
   **지난 서명을 이어 쓴 것**  5건   ← 물으신 그 길
서명이 없다  21건
```

## 서명이 없는 21건은 **아예 받은 적이 없는 분들**이다

갈라 보았다.

```
아예 없다        21건
기간이 지났다     0건
종이로만 받았다   0건
```

기간이 지나 끊긴 건도, 종이로만 받아 그림이 없는 건도 **하나도 없다.** 그분들은 아직
서명을 받지 않았다.

**한 번 받으면 그 뒤 구매부터는 저절로 이어진다.**

## 서명을 받은 뒤 이미 만든 청구서는 어떻게 되나

`MedicalAidClaimForm::attach()` 가 **서명이 파일보다 나중에 들어왔으면 다시 그린다**
(2026-09-10 확인요청 11쪽).

```php
if ($쓸수있나 && ($서명때 = self::서명시각($order)) && $서명때->gt($existing->created_at)) {
    $쓸수있나 = false;      // 다시 그린다
}
```

그러므로 서명을 받으면 그 건의 청구서도 다음에 집을 때 서명이 든 것으로 갈린다.
**서명란이 빈 청구서가 그대로 나가지 않는다.**

## 종이로 받은 위임은 청구서에 찍히지 않는다 — 일부러 그렇다

거래처 서류함에 올려 둔 **종이** 위임은 「받았다」로 세지만, **청구서의 서명란에는
얹지 않는다**(2026-10-01 잣대).

> 종이에는 서명 그림이 없으므로 그림이 들어가는 서류는 빈 채로 두어야 한다 —
> 받은 것처럼 꾸미면 서명란이 빈 청구서가 나간 것을 아무도 모른다.

지금 그런 건은 없지만, 앞으로 종이로만 받은 분이 생기면 **청구서 서명란은 빈다.**
그때는 전자서명을 따로 받아야 한다.
