# 같은 이름의 칸이 두 개라 끌어 옮길 수 없었다 (2026-10-16 확인요청)

## 신고 내용

주문 등록 화면 > 주문 목록에서 **위임동의** 칸을 끌어 옮기려 했으나 이동되지 않는다.

## 원인

그 화면의 칸 묶음은 **화면이 제 칸을 세운 뒤 공통 칸(`ceWwCols`)을 덧붙이는** 구조다.
그런데 양쪽에 같은 이름의 칸이 들어 있었다.

```
화면  { header: '서명동의', name: 'nhis_consent' }     ← 2026-10-08 추가 (SR #124ㆍ#146)
공통  { header: '위임동의', name: 'nhis_consent' }
```

머리글은 「서명동의」와 「위임동의」로 달라 보이지만 **이름이 같다.**

wwGrid 의 칸 끌기는 **이름으로** 칸을 찾는다.

```js
_reorderColumn(fromName, …) {
  const fromIdx = this.columns.findIndex(c => c.name === fromName);   // 첫째만 잡힌다
```

그리고 놓을 자리를 가릴 때도 이름으로 견준다.

```js
if (!inner || inner.dataset.colName === this._dragColName) return;   // 같은 이름 위에는 못 놓는다
```

그래서 둘째 칸(위임동의)을 끌면 **첫째 칸(서명동의)이 움직이고**, 서로의 자리로는
아예 놓을 수 없다. 담당자에게는 「끌어도 이동되지 않는다」로 보인다.

## 범위 — 세 화면

겹치는 이름을 모두 세었다. `orderKind: false` 처럼 옵션으로 꺼 둔 것과
`상세칸: false` 로 빠지는 것은 뺐다.

```
주문 관리   화면 55칸 · 공통 109칸 · **겹침 31개**
주문 등록   화면 61칸 · 공통 139칸 · **겹침  3개**   nhis_amount · nhis_consent · rx_issued
결제        화면 14칸 · 공통 140칸 · **겹침  1개**   paid_at
```

주문 관리의 31개.

```
cash_receipt · copay · deposit_amount · deposit_at · nhis_amount · nhis_claim
paid_at · pay_method · pt_basic_reeval · pt_basic_reeval_due
pt_nhis_agree_end · pt_nhis_agree_start · pt_nhis_reg · pt_nhis_reg_date
pt_nhis_renew · pt_nhis_renew_due · rx_acc_type · rx_benefit · rx_days
rx_doctor · rx_dz_code · rx_end · rx_five · rx_five110 · rx_issued
rx_license · rx_next_own · rx_order_mgr · rx_purchase · tax_invoice · total_amount
```

머리글이 조금씩 달라 **다른 칸처럼 보였다**. 몇 가지 보기.

```
copay          화면 「본인부담」   ↔ 공통 「본인 부담금」
deposit_at     화면 「입금일」     ↔ 공통 「입금 확인일」
nhis_amount    화면 「공단부담」   ↔ 공통 「청구 금액」
total_amount   화면 「금액」       ↔ 공통 「주문 금액」
paid_at        화면 「결제일」     ↔ 공통 「결제 시각」
```

이름이 같으므로 **담기는 값은 똑같다.** 같은 값이 두 칸에 서 있었다.

## 2026-10-15 에 고친 것과 다른 문제다

어제 「칸을 옮겼는데 제자리로 돌아간다」를 고쳤다 — 남겨 둔 차례가 코드를 이기던
문제였고, 코드 차례를 지문으로 담아 해결했다(커밋 `0e88ef18` 무렵).

이번 것은 **끌기 자체가 되지 않는** 문제로, 뿌리가 다르다. 어제 고친 자리는 그대로
쓸모가 있다.

## 고친 것

wwGrid 가 칸을 받을 때 **이름이 겹치면 뒤엣것을 버린다.**

```js
const 들어온칸 = options.columns || [];
const 본이름   = new Set();
const 버린것   = [];

this.columns = 들어온칸.filter(c => {
  const n = c && c.name;
  if (!n) return true;
  if (본이름.has(n)) { 버린것.push(n); return false; }
  본이름.add(n);
  return true;
});

if (버린것.length) console.warn('[wwGrid] 이름이 겹쳐 뒤엣 칸을 버렸습니다 — …');
```

**먼저 적힌 것을 남긴다.** 화면이 제 자리에 세운 칸이 의도된 자리이고, 공통 칸은
뒤에 붙는다. 무엇을 버렸는지는 콘솔에 한 번 알린다 — 조용히 지나가면 다음에 또 생긴다.

한 곳을 고쳐 모든 화면이 함께 낫는다.

## 화면에서 달라지는 것

겹치던 칸 가운데 **뒤엣것이 사라진다.** 값이 같은 칸이 하나로 줄어드는 것이라 잃는
정보는 없다.

```
주문 관리   칸 31개 줄어든다
주문 등록   칸  3개 줄어든다 — 「위임동의」ㆍ「청구 금액」ㆍ「처방전 발행일」(공통 쪽)
결제        칸  1개 줄어든다 — 「결제 시각」(공통 쪽)
```

남는 것은 화면이 세운 쪽이다 — 주문 등록이면 「서명동의」ㆍ「기관 부담금」ㆍ
「처방전 발행일」이 남고, 이제 **끌어 옮길 수 있다.**

머리글 이름이 달라 두 칸을 각각 쓰고 있었다면 그 자리는 하나로 합쳐진다. 어느 쪽
이름으로 세울지는 화면 칸의 머리글을 고치면 된다.
