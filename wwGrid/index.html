wwGrid — Withworks Data Grid

컬럼 에디터: text · number · date · checkbox · combo · 헤더 그루핑 ...

아래 버튼으로 그리드 API를 직접 호출합니다.

테마 색상 변경 (setTheme API)

1. 개요

      

        wwGrid는 외부 라이브러리 없이 순수 JavaScript(ES6+)로 구현한 데이터 그리드입니다.
        wwGrid.js와 wwGrid.css 두 파일만 포함하면 바로 사용할 수 있습니다.
      

      
    
        
  • 컬럼 에디터: text · number · date · checkbox · combo · popup
    • 
        
  • 헤더 그루핑 (2단 헤더), 컬럼 정렬 / 드래그 순서 변경 / 너비 조절
    • 
        
  • 행 추가 · 삭제 · 수정 추적 · 변경 취소
    • 
        
  • 숫자 천단위 콤마 · Sum 행 · 엑셀(.xls) 다운로드
    • 
        
  • CSS 변수 기반 색상 테마 (인스턴스별 독립 적용)
    • 
        
  • 하단 상태바 (전체 / 선택 / 수정 건수) 항목별 제어
    • 
      

    


    
    

      
2. 설치

      
별도 빌드 과정 없이 파일 두 개를 HTML에 포함합니다.


<link rel="stylesheet" href="wwGrid.css">
<script src="wwGrid.js"></script>

      
CDN 미지원. wwGrid.js · wwGrid.css를 프로젝트에 직접 복사해 사용하세요.

4. 그리드 옵션

      

        
옵션타입기본값설명

        
          
el 필수HTMLElement—그리드를 마운트할 DOM 요소

          
columns 필수Array—컬럼 정의 배열 (§5 참고)

          
dataArray[]초기 데이터 배열 (객체 배열)

          
columnGroupsArray[]헤더 그루핑 정의 (§6 참고)

          
rowKeystringnull고유 키 컬럼명 (현재 참고용)

          
heightnumbernull스크롤 영역 최대 높이(px). 생략 시 자동

          
rowCheckboxbooleantrue행 선택 체크박스 표시 여부

          
rowNumberbooleantrue행 번호(No) 열 표시 여부

          
editablebooleantrue전체 편집 가능 여부 (false 시 모든 셀 읽기 전용)

          
summarybooleanfalse숫자 컬럼 합계 행(Sum Row) 표시 여부

          
toolbarbooleantruetrue: 엑셀 버튼 표시 / false: 툴바 숨김

          
footerboolean | objecttrue하단 상태바 제어 (§7 참고)

          
themeobject{}초기 색상 테마 (§8 참고)

        
      

    


    
    

      
5. 컬럼 옵션

      

        
옵션타입기본값설명

        
          
header 필수string—헤더에 표시할 컬럼 제목

          
name 필수string—데이터 객체의 키명 (고유해야 함)

          
widthnumber100컬럼 너비(px)

          
editorstringnull에디터 유형: text · number · date · checkbox · combo · popup

          
sortablebooleantrue헤더 클릭 정렬 활성화 여부

          
alignstring—셀 정렬: left · center · right (number 에디터는 자동 우측 정렬)

          
defaultValueany—행 추가 시 기본값

          
optionsArray—combo 에디터 전용. [{value, label}] 또는 문자열 배열

          
min / max / stepnumber—number 에디터 전용. 입력 범위 및 증감 단위

          
popupobject—popup 에디터 전용 설정 (§5-6 참고)

          
summarybooleantruefalse로 설정 시 해당 숫자 컬럼을 Sum 행에서 제외

          
exportablebooleantruefalse로 설정 시 엑셀 다운로드에서 해당 컬럼 제외

        
      


      
5-1. text 에디터


{ header: '이름', name: 'name', width: 120, editor: 'text', sortable: true }


      
5-2. number 에디터

      
숫자 입력. 표시 시 천단위 콤마 자동 적용, 우측 정렬. Sum 행 집계 대상.


{ header: '연봉(만원)', name: 'salary', width: 110, editor: 'number',
  min: 0, max: 99999, step: 100 }


      
5-3. date 에디터

      
클릭 시 달력 팝업이 열립니다. 값 형식: YYYY-MM-DD


{ header: '입사일', name: 'joinDate', width: 120, editor: 'date', sortable: true }


      
5-4. checkbox 에디터

      
불리언 값(true/false)을 체크박스로 표시·편집합니다.


{ header: '재직중', name: 'active', width: 70, editor: 'checkbox' }


      
5-5. combo 에디터

      
선택 목록에서 값을 선택합니다. options는 문자열 배열 또는 {value, label} 객체 배열.


{ header: '부서', name: 'dept', width: 110, editor: 'combo',
  options: [
    { value: 'dev',    label: '개발팀' },
    { value: 'design', label: '디자인팀' },
    { value: 'pm',     label: 'PM팀' },
  ]
}


      
5-6. code 에디터 (코드 직접 입력 + API 조회)

      
셀에 코드를 직접 입력하고 Enter/Tab/포커스 아웃 시 onLookup 함수를 호출합니다. 조회 성공 시 라벨을 표시하고, 실패 시 셀 안에 에러 메시지를 인라인으로 표시한 뒤 2.5초 후 이전 값으로 복원합니다.


{ header: '팀코드', name: 'teamCode', width: 140,
  editor: 'code',
  placeholder:    'T001 ~ T006',           // 입력창 안내 텍스트 (선택)
  errorMessage:   '존재하지 않는 팀코드', // 조회 실패 메시지 (선택, 기본: '코드를 찾을 수 없습니다')
  onLookup: async (code) => {
    // code: 사용자가 입력한 코드 문자열
    // 반환: { value, label } 객체 또는 null(실패)
    const res = await fetch(`/api/team/${encodeURIComponent(code)}`);
    if (!res.ok) return null;           // null 반환 → 에러 메시지 표시
    const data = await res.json();
    return { value: data.teamCode, label: data.teamName };
  },
}

      

        동작 흐름:
        Enter · Tab · 포커스 아웃 → 셀에 스피너 표시 → onLookup(code) 호출 →
        성공 시 라벨 표시 · 값 저장 / 실패 시 에러 배지 표시(흔들림 애니메이션) → 2.5초 후 이전 값 복원
      


      
5-7. popup 에디터

      
셀 클릭 시 모달 팝업이 열립니다. popup 객체에 아래 세 가지 방식 중 하나를 사용합니다.

      

        
방식옵션설명

        
          
내장 목록popup.items배열 데이터를 내장 검색 목록으로 표시. 클라이언트 필터링

          
외부 API 검색popup.onSearch입력할 때마다 비동기 함수 호출 (300ms 디바운스). 서버/API 검색에 적합

          
커스텀 렌더러popup.render모달 바디 DOM을 직접 렌더링하는 함수. 완전 자유 형태

        
      


// ① 내장 목록 (items)
{ header: '담당자', name: 'manager', editor: 'popup',
  popup: {
    title: '담당자 선택', width: 420, height: 380,
    items: [
      { value: 'EMP001', label: '홍길동', sub: '개발팀 · 수석' },
      { value: 'EMP002', label: '이영희', sub: '디자인팀 · 리드' },
    ],
  }
}

// ② 외부 API 검색 (onSearch)
//    - async 함수로 정의, 반환값: [{ value, label, sub? }]
//    - 입력 300ms 후 자동 호출 (디바운스), Enter 키로 즉시 검색
//    - 응답 역전(race condition) 자동 방지
{ header: '부서코드', name: 'deptCode', editor: 'popup',
  popup: {
    title: '부서 코드 검색', width: 440, height: 400,
    onSearch: async (query) => {
      const res = await fetch(`/api/dept/search?q=${encodeURIComponent(query)}`);
      const data = await res.json();
      // 반환 형식: [{ value: 'D001', label: '개발1팀', sub: '기술본부' }, ...]
      return data;
    },
  }
}

// ③ 커스텀 렌더러 (render)
{ header: '첨부파일', name: 'file', editor: 'popup',
  popup: {
    title: '파일 선택', width: 500, height: 460,
    render: (container, currentValue, done) => {
      // container: 모달 바디 HTMLElement
      // currentValue: 현재 셀 값
      // done(value, label): 선택 완료 시 호출 → 셀에 값 반영
      const btn = document.createElement('button');
      btn.textContent = '파일 선택';
      btn.onclick = () => done('file_001.pdf', 'file_001.pdf');
      container.appendChild(btn);
    },
  }
}

    


    
    

      
6. 헤더 그루핑

      
columnGroups 옵션으로 컬럼을 묶어 2단 헤더를 표시합니다.


const grid = new wwGrid({
  columnGroups: [
    { header: '기본 정보', children: ['name', 'dept', 'position'] },
    { header: '근무 정보', children: ['salary', 'joinDate', 'active'] },
  ],
  columns: [
    { header: '이름',   name: 'name',     ... },
    { header: '부서',   name: 'dept',     ... },
    { header: '직급',   name: 'position', ... },
    { header: '연봉',   name: 'salary',   ... },
    { header: '입사일', name: 'joinDate', ... },
    { header: '재직중', name: 'active',   ... },
  ],
  ...
});

      
children에 지정한 컬럼명은 columns 배열에서 연속해서 정의해야 합니다. 컬럼 드래그로 순서가 바뀌어 그룹이 끊기면 해당 그룹은 자동으로 해제됩니다.

    


    
    

      
7. 하단 상태바 (footer)

      

        
값동작

        
          
footer: true 기본전체건수 · 선택건수 · 수정건수 모두 표시

// 수정건수만 표시
footer: { total: false, selected: false, modified: true }

// 상태바 숨김
footer: false

    


    
    

      
8. 색상 테마

      
생성 시 theme 옵션 또는 런타임에 setTheme()로 변경합니다. 변경은 해당 그리드 인스턴스에만 적용됩니다.

      

        
키CSS 변수기본값설명

        
          
accent--cg-accent#3c82c4강조색 (버튼·정렬 아이콘·편집 테두리)

          
accentDark--cg-accent-dark#2a6aad강조색 hover 상태

          
headerBg--cg-header-bg#f0f3f7헤더 배경

          
headerGroupBg--cg-header-group-bg#d8e3ef그룹 헤더 배경

          
headerHoverBg--cg-header-hover-bg#dde6f0헤더 hover 배경

          
footerBg--cg-footer-bg#f0f3f7하단 상태바 배경

          
selectedBg--cg-selected-bg#ddeeff선택 행 배경

          
modifiedBg--cg-modified-bg#fff8e6수정 행 배경

          
newBg--cg-new-bg#f0fff4신규 추가 행 배경

          
summaryBg--cg-summary-bg#eef2f8합계(Sum) 행 배경

          
border--cg-border#c0c8d0외곽·헤더·푸터·달력 테두리 색

          
rowBorder--cg-row-border#e4e8ed행·셀 구분선 색

          
borderSub--cg-border-sub#b0bcc8버튼·Sum 상단선 색

        
      


// 생성 시 테마 설정
const grid = new wwGrid({
  theme: {
    accent:     '#e05050',
    selectedBg: '#fde8e8',
    headerBg:   '#fff0f0',
  },
  ...
});

// 런타임 변경 (기존 테마와 병합됨)
grid.setTheme({ accent: '#4caf50', headerBg: '#f0fff4' });

    


    
    

      
9. API 메소드


      
데이터 조회

      

        
메소드반환설명

        
          
getData()Array현재 전체 데이터 스냅샷 반환 (깊은 복사)

          
getCheckedRows()Array체크된 행 데이터 배열 반환. 각 객체에 _rowIndex 포함

          
getModifiedRows()object수정 데이터 반환. { updated, added, deleted } 형태

          
getModifiedJSON()stringgetModifiedRows() 결과를 JSON 문자열로 반환

        
      


      
데이터 조작

      

        
메소드파라미터설명

        
          
addRow(rowData?)object (선택)새 행 추가. rowData 생략 시 컬럼 기본값으로 빈 행 추가. 추가 후 첫 편집 가능 셀로 자동 포커스

          
removeCheckedRows()—체크된 행 삭제. 체크 행 없으면 알림. 삭제된 원본 행은 getModifiedRows().deleted에 포함

          
setValue(rowIndex, colName, value)number, string, any특정 셀 값 변경. 수정 추적 포함

          
setData(data)Array전체 데이터 교체. 수정·선택 상태 초기화

          
resetModified()—모든 변경사항 취소. 최초 로드 데이터(_initialData)로 복원

        
      


      
기타

      

        
메소드파라미터설명

        
          
setTheme(theme)object테마 색상 런타임 변경. 기존 테마와 병합

          
downloadExcel(opts?)object (선택)엑셀(.xls) 파일 다운로드 (§10 참고)

          
_showModifiedDialog()—수정 데이터를 팝업으로 표시. 클립보드 복사 지원

        
      


      
getModifiedRows() 반환 형식


{
  updated: [                        // 기존 행이 수정된 경우
    {
      original: { id: 1, name: '홍길동', salary: 5000, ... },  // 수정 전 원본
      current:  { id: 1, name: '홍길동', salary: 5500, ... },  // 현재 값
      changed:  { salary: 5500 }                               // 변경된 필드만
    },
    ...
  ],
  added: [                          // addRow()로 추가된 신규 행
    { name: '신규직원', dept: 'dev', salary: 3000, ... },
    ...
  ],
  deleted: [                        // removeCheckedRows()로 삭제된 원본 행
    { id: 3, name: '박지호', ... },
    ...
  ]
}

    


    
    

      
10. 엑셀 다운로드

      
downloadExcel(opts) 메소드로 현재 그리드 데이터를 .xls 파일로 내보냅니다. 외부 라이브러리 없이 XML Spreadsheet 2003 형식으로 생성합니다.

      

        
옵션타입기본값설명

        
          
filenamestring'grid_export'저장 파일명 (확장자 제외)

          
sheetNamestring'Sheet1'워크시트 이름

          
checkedOnlybooleanfalsetrue 시 체크된 행만 출력

          
includeSummaryboolean그리드 summary 설정값합계 행 포함 여부

        
      


// 전체 데이터 저장
grid.downloadExcel({ filename: '직원목록', sheetName: '직원' });

// 체크된 행만 저장
grid.downloadExcel({ checkedOnly: true, filename: '선택_직원' });

// 합계 행 포함
grid.downloadExcel({ includeSummary: true });

      
헤더 그루핑이 있으면 Excel에서도 2행 헤더로 출력됩니다. 숫자 컬럼은 Excel 숫자 형식으로 저장되어 합계·평균 등 수식을 바로 적용할 수 있습니다.

    


    
    

      
11. 외부 버튼 연동

      
그리드 내장 툴바(toolbar)는 엑셀 버튼만 제공합니다. 행 추가·삭제·변경 취소 등의 버튼은 외부에서 직접 API를 호출해 구성합니다.


<!-- HTML: 그리드 위에 버튼 배치 -->
<div>
  <button onclick="grid.addRow()">+ 행 추가</button>
  <button onclick="grid.removeCheckedRows()">행 삭제</button>
  <button onclick="grid.resetModified()">변경 취소</button>
  <button onclick="grid._showModifiedDialog()">수정 데이터 추출</button>
</div>
<div id="myGrid"></div>

<!-- 툴바 완전 숨김 시 -->
<script>
const grid = new wwGrid({
  toolbar: false,   // 엑셀 버튼도 숨기려면 false
  ...
});
</script>

    


    
    

      
12. 컬럼 인터랙션

      
    
        
  • 정렬: 헤더 클릭. 같은 컬럼 재클릭 시 오름차순 ↔ 내림차순 전환. 정렬 후 수정·선택 상태는 초기화됩니다.
    •
