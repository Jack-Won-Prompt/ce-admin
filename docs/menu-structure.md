# CE-Admin 메뉴 구조

기준: 2026-08-04 · 좌측 사이드바 순서 그대로

메뉴는 두 곳이 함께 쥔다 — 화면에 그리는 것은 `resources/views/layouts/app.blade.php`,
권한과 라우트 매칭은 `config/permissions.php`. 항목을 늘리면 두 곳 모두 손봐야 한다.

권한 열의 뜻 — 조회 / 등록 / 수정 / 삭제 / 발송(발행·전송).
`관리자 전용`은 권한 그룹과 무관하게 `admin` 계정만 열 수 있다.

## 메뉴에 없는 화면

사이드바에 항목이 없고 다른 화면에서 열리는 것들이다.

| 화면 | 여는 곳 |
|---|---|
| 처방전 검수·주문 연계 | 처방전 목록·대시보드·거래처 관리에서 행을 더블 클릭 |
| 주문 상세 | 주문 관리에서 행 선택 |
| 문의·공지·CE샵 주문 상세 | 각 목록에서 행 선택 |
| 위임동의 서명 페이지 | 환자에게 보낸 SMS 링크 (로그인 없이 열림) |
| 개인정보 수집·이용 동의 | 외부 링크 (로그인 없이 열림) |
