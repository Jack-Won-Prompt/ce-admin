## 2. 개발 — 적용한 업무

### 2.1 전 화면 규격 통일

시안에서 실제로 쓰이는 값만 남겼습니다.

| 항목 | 정리 결과 |
|---|---|
| 글자 굵기 | 400 · 500 · 700 **세 가지** |
| 글자 크기 | 10 · 11 · 12 · 13 · 14 · 16 **여섯 가지** |
| 모서리 | 6 · 8 · 12 · 알약형 **네 가지** |
| 색 | primary · gray · alert **세 계열**로 통일 |

색은 뜻에 따라 네 단계로 갈랐습니다 — 완료·성공 / 부가 정보 / 대기·중립 / 주의·실패.
초록·남색·보라·하늘·주황이 섞여 있던 것을 정리한 결과입니다.

> 카카오 브랜드색(노랑)과 현금영수증 인쇄 판형은 손대지 않았습니다.
> 브랜드 자산이고, 인쇄물은 화면 색 규칙을 따르지 않습니다.

---

### 2.2 목록 화면 — 그리드 규격 전역 통일

목록 화면 12개가 함께 바뀝니다.

- 표 머리행의 **세로 구분선 제거**, 아래 선만 남김
- 머리글·본문 셀 **전부 왼쪽 정렬** (수량·금액 같은 숫자 포함 — 시안 기준)
- 체크박스를 16×16 둥근 모양으로 (브라우저 기본 각진 모양 대신)
- 검색 카드의 구분선·간격을 시안 실측값으로
- 그리드를 흰 카드 안에 넣고, 그리드 자체 테두리는 제거

### 2.3 주문 관리·상세 재구성

**주문 상세**의 구조가 시안과 달랐습니다. 제목 줄과 탭이 위아래로 나뉘고 카드가
세로로 쌓여 있던 것을, 시안대로 **제목과 탭을 한 줄에** 두고 카드를 가로로 놓았습니다.

| 탭 | 배치 |
|---|---|
| 기본 정보 | 진행 단계(전체 폭) + 3열 [환자 정보][제품 정보][금액 정보] |
| 배송/상태 | 3열 [배송 정보][Withworks 출고 현황][상태 변경] |
| 청구/발행 | 2열 |
| 메모/정보 | 2열 |

카드 안 항목을 **[라벨 왼쪽 / 값 오른쪽]** 회색 상자로 바꿨습니다. 주민등록번호와
전화번호가 가운뎃점으로 이어진 한 줄이던 것도 라벨 붙은 두 칸으로 나눴습니다.

**진행 단계에 시안 그림 적용** — 주문서·체크·트럭·상자 네 가지 그림을 넣었습니다.
그전에는 회색 원 안의 점과 체크였습니다.

### 2.4 처방전 검수 화면

매일 쓰는 핵심 화면이라 측정 → 글자 → 색 → 치수 → 이중 검증 순으로 진행했습니다.

| 항목 | 내용 |
|---|---|
| 환자 정보 바 | 시안대로 **아바타 + 두 줄** (이름·칩 / 전화·병원·담당) |
| 주소 줄 | 1줄 [우편번호][도로명][주소 검색] / 2줄 [상세 주소][배송 주소 동일] |
| 현금영수증 | [소득공제][현금영수증 번호] 두 칸을 한 줄로 |
| 뷰어 왼쪽 | 이미지 아래 카드들을 상자 안에 정리 |
| 문서 썸네일 | 고른 것만 테두리 표시 |
| 메모 입력 | 높이 80 → 112 |
| 배송 주소 동일 | 체크 표시가 반대로 칠해져 있던 것 정정 |

### 2.5 업로드 제한을 화면에 표시

**처방자료 업로드**와 **서류 관리** 카드 머리에 제한을 배지로 적었습니다.

```
처방자료 업로드   최대 50MB · JPG/PNG/PDF/HEIC · 최대 10개
서류 관리         PDF/JPG/PNG/HEIC · 최대 50MB
```

새로 만든 규칙이 아니라 **이미 적용 중인 제한을 화면에 드러낸 것**입니다.
서버 검증·화면 경고·파일 선택창 세 곳과 대조해 문구를 맞췄습니다.

### 2.7 겪고 있던 결함 8건 수정

시안 대조 중에 드러난 것들입니다. 디자인 문제가 아니라 **읽히지 않거나 보이지 않던** 것입니다.

| 화면 | 증상 |
|---|---|
| 목록 4개 | 안내 문장이 갈라져 `행을 더블클릭 하면` 처럼 띄어 읽혔음 |
| 서류 관리 | 등록 안내문이 세로로 토막나 `등록한 서/류는` 처럼 읽는 순서가 무너짐 |
| 발송 내역 상세 | 정보 행 **32개의 구분선이 통째로 사라져** 있었고 글자가 붙어 있었음 |
| 주문 상세 | 운송장 번호 입력칸이 좁은 화면에서 **30px** 까지 줄어 보이지 않았음 |
| 주문 상세 | 메모가 없으면 카드가 전폭으로 늘어나 라벨과 값이 **1,500px** 떨어져 읽을 수 없었음 |
| 검수 화면 | **'소득공제' 라벨**이 화면에서 사라져 무슨 칸인지 알 수 없었음 |
| 전 화면 | 빈 상태 안내 글자가 흐려 대비 **2.70:1** (권장 4.5:1 미달) → 5.32:1 |
| 서류 관리 | 첨부 유형 라벨 대비 **3.03:1** → 4.58:1 |
