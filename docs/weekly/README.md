# 주간 보고

매주 **화요일**에 지난 화요일부터 당일까지의 작업을 정리한다.
파일 이름은 보고일 기준 `YYYY-MM-DD.md`.

## 목록

| 보고일 | 대상 기간 | 주요 내용 |
|---|---|---|
| [2026-08-04](2026-08-04.md) | 07-28 ~ 08-04 | 주민등록번호 암호화(P0-1) · 권한 그룹 체계 · 디자인 시스템 전면 적용 · 서비스 연동 설정 |

## 작성 규칙

**담는 것** — 새로 만든 기능, 적용한 업무, 운영에 영향을 주는 변경, 확인·조치가 필요한 사항.

**빼는 것** — 작업 중 생긴 오류를 되돌린 수정, 문구·간격 같은 미세 조정.
보고는 "무엇이 달라졌나"를 전하는 자리이지 작업 일지가 아니다.

**쓰는 법** — 기능 이름이 아니라 **무엇이 가능해졌는지**로 적는다.
"왜 필요했나 → 무엇을 했나 → 지금 어떤 상태인가" 순으로 쓰면 읽는 쪽이 판단할 수 있다.

## 지난 기간의 작업 뽑기

```bash
# 지난 화요일부터 오늘까지
git log --since="YYYY-MM-DD 00:00" --date=format:"%m-%d(%a)" --pretty=format:"%h|%ad|%s"

# 규모
git diff --shortstat <시작커밋>^ HEAD
git diff --name-status <시작커밋>^ HEAD | grep "^A"
```

## 틀

```markdown
# CE-Admin 주간 보고 — YYYY-MM-DD ~ YYYY-MM-DD

1. 요약            — 이번 주를 몇 줄로. 지표 표 하나.
2. 개발 — 적용한 업무 — 주제별로. 왜 필요했는지부터.
3. 적용(배포) 현황   — 운영 반영 완료 / 대기. 배포 절차.
4. 확인·조치가 필요한 사항 — 담당을 적는다. 이 표가 보고의 핵심이다.
5. 다음 주 계획
```
