## 4. 검증할 때 쓰는 방법 (이 저장소 관행)

- **화면 확인** — 브라우저 로그인 비밀번호를 모른다. 실제 HTTP 커널로 라우트를 태우고
  (`Request::create` + `$kernel->handle`, CSRF 만 pass-through, `Auth::guard('web')->setUser()`),
  렌더 결과를 `public/` 에 써서 크롬으로 연다. 열 때 자산 경로를 `http://localhost/ce-admin/public/` 로
  바꿔야 wwGrid 가 뜬다. **확인 뒤 `public/` 임시 파일은 반드시 지운다.**
- **PDF 생성은 메모리를 많이 쓴다** — CLI 로 돌릴 때 `php -d memory_limit=1024M` 를 붙인다(P5).
- CLI PHP 는 `/e/php/php-8.5.3/php.exe`, 아파치 PHP 는 `/e/xampp/php/php.exe` 로 서로 다르다.
- 이 서버에는 **Imagick·Ghostscript·poppler 가 없다.** PDF→이미지 변환이 필요하면 GD 로 직접 그린다
  (`app/Support/TaxInvoiceImage.php` 가 그 예, 한글은 `storage/fonts/NanumGothic.ttf`).
- **AWS Textract 미설정** — `prescriptions/analyze` 경로는 로컬에서 못 쓴다. 처방전을 만들 때는
  `GET /prescriptions/create` → `POST /prescriptions/{rx}/ocr` → `POST .../attachments` 경로를 쓴다.
