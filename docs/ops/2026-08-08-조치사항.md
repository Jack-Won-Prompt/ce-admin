## 배포 절차

이번 기간의 커밋 7건이 한 번에 나간다.

```bash
cd /home/ubuntu/www/lcpoint
git pull
php artisan migrate
php artisan optimize:clear
```

### `migrate` 가 필요한 이유

밀려 있는 마이그레이션이 **두 개**다.

| 마이그레이션 | 안 돌리면 |
|---|---|
| `settings` (지난 기간) | **설정 › 서비스 연동 설정** 화면이 500 |
| `add_updated_by_to_prescriptions` | 처방전 **저장 시 오류** |

`updated_by` 쪽이 더 급하다. 설정 화면은 그 화면만 열리지 않는 반면, 이쪽은
검수 화면에서 저장을 누를 때마다 실패한다.

**확인**

```bash
php artisan tinker --execute="dump(Schema::hasColumn('prescriptions','updated_by'), Schema::hasTable('settings'));"
```

`true true` 여야 한다.

> 2026-08-07 운영에서 `php artisan migrate` 가 `Nothing to migrate` 를 냈다.
> pull 전이었을 가능성이 높다. 위 확인을 반드시 거칠 것.

### `optimize:clear` 가 필요한 이유

이번 배포는 **설정·라우트·뷰 세 캐시가 모두** 낡는다.

| 바뀐 것 | 낡는 캐시 |
|---|---|
| `config/permissions.php` — 페이지 1개 추가, override 1개 | 설정 |
| 라우트 추가 3개 (`consentSignature`, `prescription-consents.index`, `.store`) | 라우트 |
| 라우트 삭제 1개 (`revealResidentNo`) | 라우트 |
| 화면 전반 (레이아웃 CSS · Blade 구조) | 뷰 |

라우트 캐시가 낡으면 검수 화면이 `route()` 해석 단계에서 **500** 으로 죽는다.
2026-08-06 운영 500 이 정확히 이 원인이었다.

### 정적 파일

`public/vendor/wwgrid/wwGrid.js` 가 바뀌었다. 파일 시각이 주소에 붙어 나가므로

(`Ctrl+Shift+R`) 한 번.
