## 서버 설정

### 1. 업로드 파일 개수 — `php.ini`

처방자료 업로드 상한을 10개에서 **40개**로 올렸다. 화면과 서버 검증은 40개를 받지만
**PHP 기본값이 20개**라, 그대로 두면 21번째부터 **조용히 사라진다**(오류도 나지 않는다).

```ini
; /etc/php/8.x/fpm/php.ini
max_file_uploads = 50
post_max_size = 100M      ; 파일 합계보다 넉넉히
upload_max_filesize = 50M ; 한 파일 50MB 제한과 맞춘다
```

```bash
sudo systemctl reload php8.x-fpm
```

**확인** — 처방자료 업로드에서 파일 25개를 골라 등록한 뒤, 등록된 건수가 25인지 본다.

### 2. 무통장입금 계좌 — 화면 설정

값을 받는 대로 **설정 › 서비스 연동 설정 › 토스페이먼츠**의 `입금계좌 은행` ·
`입금계좌 번호`에 넣는다. 비어 있으면 결제 안내 문자에 「입금 계좌는 담당자에게
문의해 주십시오」로 나간다.
