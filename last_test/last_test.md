## 아직 남은 것

1. **정산ㆍ주문ㆍ처방전 화면의 `is_done` 자리 스물 남짓** — 부분 취소된 건의 입금 금액이 그 화면들에서는 아직 「-」로 선다. `SettlementController`ㆍ`OrderGridExtras`ㆍ`orders/show.blade.php` 등. 다른 세션(ce-admin-3f)이 보는 파일이라 손대지 않았다.
2. **RN202609280002 의 `refund_amount` 가 22,500원** — 고치기 **전에** 환불한 건이다. 시험 이력은 지우지 않는다는 지시에 따라 그대로 둔다. 고친 뒤의 건은 실제 금액이 적힌다.
3. **잘못 나간 링크 #221 (42,000원)** — `cancelled` 로 닫고 사유를 적어 두었다. 주문 577 의 총액은 37,500원으로 되돌렸다.
4. **위드웍스에 보낼 요청 둘** (정현우)
   - 반품 웹훅에 `inspection` 묶음 : `result`(ok|defect) · `defect_qty` · `defect_note` · `received_qty` · `expected_qty` — **CE Admin 은 이미 받아 담는다.** 보내지 않으면 책임자가 화면에서 고른다
   - `return_status` 에 `reject_reason` 칸 — 반려 사유를 창고 화면에 전하려면 필요하다. 지금은 상태만 가고 사유는 우리 쪽에만 남는다
5. **권한 나눠 주기** — 지금은 모두 「전체 권한」이라 책임자ㆍ최종승인자가 갈리지 않는다. 설정 › 권한 그룹에서 「책임자 검수 승인 · 반려」와 「최종승인자 서명」을 따로 부여해야 두 걸음이 실제로 두 사람이 된다
6. **환불 실패 → 재시도 단추** 는 화면에 세워 두었으나, 토스가 실패하는 자리를 시험에서 만들지 못했다 (test 환경에서 취소가 늘 성공했다). 운영 전환 뒤 확인할 자리다
