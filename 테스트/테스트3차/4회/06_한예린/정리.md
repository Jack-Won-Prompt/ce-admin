5번 정시우의 지자체 건에 세운 문(⑤)과 **정확히 같은 결**이다 — 낼 곳이 아닌 곳으로
서류가 가지 않게 한다.

| 어디 | 무엇 |
|---|---|
| 화면 | 공단 자리를 **잠그고** 「기타(직접 입력)」로 연다 · 지사 목록을 접는다 |
| 서버 | 수신처가 공단이면서 청구처가 `none` 이면 **422** |

**보내는 길 자체는 막지 않았다** — 근로복지공단ㆍ보험사로 증빙을 보내는 일이

**운영에서 두 겹 다 확인했다.**

## 동의 화면에서 걸린 자리 (결함 아님 · 새길 것)

서명 단추가 열리지 않아 한참 들여다봤다. 까닭은 **제3자 제공 동의 라디오가
카테터ㆍ장루 두 벌인데 무리 이름(`agree_third_party`)을 함께 쓰기 때문**이다.

```js
agreePicked(name) {
  const el = document.querySelector(`input[name="${name}"]:checked`);
  const only = el?.closest('[data-only]')?.dataset.only;
  if (only && only !== privacyType()) return '';   // ← 접힌 유형의 답은 없는 것으로 친다
```

장루 쪽(숨은) 칸이 켜져 있으면 `:checked` 가 그것을 먼저 집어 **''** 를 돌려주고,
`privacyReady()` 가 거짓이 되어 단추가 잠긴다. 화면은 **왜 잠겼는지 말하지 않는다.**

사람이 쓰는 길에서는 접힌 칸을 누를 수 없어 결함이라 부르지 않았다. 다만
**단추가 잠겼을 때 무엇이 모자란지 알려 주면** 이런 자리에서 헤매지 않는다.
