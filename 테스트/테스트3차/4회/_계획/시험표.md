## 처방전 읽는 법

처방전 위쪽 **빨간 띠**는 시험용 표지다 — 발행일ㆍ가상 성명ㆍ가상 병원ㆍ
테스트 주민번호ㆍ테스트 휴대폰. 그 아래가 **실제 서식**이다.

| 처방전에서 읽는 것 | 어느 칸으로 |
|---|---|
| (띠) 가상 성명 | 이름 |
| (띠) 테스트 주민번호 | 주민등록번호 → 생년월일 자동 |
| (띠) 가상 병원 | 병원명 |
| (띠) 발행일 | 처방전 발행일 |
| 진료과목 | 전문과목 |
| 상병명 · **상병코드** | 상병 명 · 상병코드 |
| **1일 처방개수** | 1일 처방 개수 |
| **총 처방기간** | 총 처방일수 · 처방전 사용 기간 |
| **총계** | 총계 — **주문 수량의 근거** |
| 요양기관명(기호) | 요양기관 코드 |
| 담당의사성명(면허번호) | 담당 의사명 · 의사면허번호 |

> **손글씨의 「수진자 성명」은 원본 스캔에 남아 있는 것**이라 띠의 가상 성명과 다르다.
> 사람은 **띠의 가상 성명**(폴더 이름과 같다)으로 세운다.

**처방전에도 없는 칸**(진단 확인일ㆍ상병 구분ㆍ요류역학검사일 등)만 시험값으로 넣고,
사람마다 정리.md 에 **자료에서 온 값과 시험값을 갈라 적는다.**

## 켜 둔 안전 장치

| 열쇠 | 값 | 뜻 |
|---|---|---|
| `POPBILL_SMS_SIMULATE` | true | 문자가 실제로 나가지 않는다 |
| `POPBILL_FAX_SIMULATE` | **false** | **팩스는 팝빌 운영으로 실제 나간다** |
| 받는 팩스번호 | **`02-0000-0000`** | 가입자 국번이 0 으로 시작하지 않아 **누구에게도 닿지 않는다** |
| `POPBILL_ISSUE_SIMULATE` | true | 세금계산서ㆍ현금영수증이 국세청에 나가지 않는다 |
| `NHIS_EFAX_DRIVER` | simulation | 자동 공단 팩스가 나가지 않는다 |
| `NICE_SIMULATE` | true | 본인확인이 「확인됨 (시험)」으로 지나간다 |
| `TOSS_TEST_MODE` | true | 결제는 토스 시험 환경 |

> **시험이 끝나면** 청구처 팩스번호를 실제 지사 번호로 되돌리고,
> 팝빌 전송 내역을 확인한 뒤 지운다.
