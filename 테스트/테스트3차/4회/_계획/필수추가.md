# 반드시 더 만들어야 하는 것

> 2026-09-05 지시 — 「둘 다 만들어야 하는 건 필수」.
> 4회 시험을 마친 뒤 이어서 만든다.

## ① 공단 재등록 대기 목록 화면 — 필수

**지금** 기한 2주 전부터 담당자에게 **토스트와 채팅**으로만 알린다
(`NhisRenewNotice` · 커밋 배포 완료).

**없는 것** 한눈에 보는 **목록**이 없다. 담당자가 자리를 비웠거나 알림을 흘려보내면
그 건은 다시 눈에 띄지 않는다. 채팅을 거슬러 올라가 찾아야 한다.

**만들 것**

| | |
|---|---|
| 어디 | `환자ㆍ처방` 아래 「**재등록 대기**」 또는 거래처 관리의 거르개 |
| 무엇을 보이나 | 이름 · 연락처 · **재등록 기한** · **남은 날** · 담당자 · 마지막 안내 보낸 때 |
| 어떻게 고르나 | 기한이 **2주 안** / **이미 지난 것**(석 달까지) / 전체 |
| 차례 | 기한이 가까운 것부터. **지난 것이 맨 위** |
| 함께 | 그 줄에서 곧바로 「재등록 안내 보내기」(②)로 갈 수 있게 |

**왜 필수인가** 기한을 놓치면 자격이 끊긴다. 그 뒤에 나간 물건은 공단에 청구할 수
없고 **이미 보낸 값은 우리가 떠안는다.** 알림 하나에 기대기에는 잃는 것이 크다.

## ② 재등록 안내 문자 보내는 자리 — 필수

**지금** 알림이 「환자에게 알려 주십시오(문자ㆍ전화)」라고만 말한다.
담당자가 기존 SMS 단추로 **손수 써서** 보내야 한다.

**없는 것** 재등록 안내 **서식**과 **보낸 자취**가 없다. 사람마다 다르게 적히고,
누구에게 언제 보냈는지 남지 않는다.

**만들 것**

| | |
|---|---|
| 어디 | 거래처 상세ㆍ주문 등록의 「재등록 안내」 단추 · 목록(①)의 줄에서도 |
| 서식 | 「○○○님, 자가도뇨 소모성재료 공단 등록이 **YYYY-MM-DD** 에 끝납니다. 그 전에 재등록을 하셔야 급여가 이어집니다. 문의 1588-7866」 |
| 무엇이 채워지나 | 이름 · **재등록 기한** · 남은 날 |
| 자취 | 보낸 때ㆍ보낸 사람ㆍ받는 번호를 남긴다(발송/발행 내역에도 선다) |
| 전화 상담 | 문자를 보낸 뒤 **상담 기록**을 남길 수 있게 — 통화했는지, 뭐라 했는지 |

**왜 필수인가** 「알려 줘야 한다」와 「알렸다」는 다른 일이다. 자취가 없으면 나중에
환자가 「못 들었다」고 할 때 댈 것이 없고, 담당자가 바뀌면 누가 어디까지 했는지 모른다.

## 아직 안 정한 것

- 재등록 안내를 **몇 번** 보내는가 — 2주 전 한 번인가, 지나서도 다시 보내는가
- **알림톡**으로도 보내는가 (문자만인가)
- 재등록을 **마쳤다**는 것을 어디에 적는가 — 건보등록 상태를 「재등록 완료」로 바꾸면
  기한이 다시 2년 뒤로 밀려야 하는가
