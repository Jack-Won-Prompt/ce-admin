## 미성년 갈래 — 이번에 고친 것

### ㉕ 보호자가 거래처에 남지 않던 것 (고침)

`patients.guardian_*` 칸은 진작 있었는데 **채우는 화면이 없었다.** 보호자는 위임동의
한 건에만 남아, 같은 아이의 다음 처방전에서 처음부터 다시 묻고 거래처 관리에서
「이 아이의 보호자가 누구냐」에 답할 자리가 없었다.

길을 셋 냈다.

| 어디 | 무엇 |
|---|---|
| 거래처 수정 창 · 거래처 상세 | 보호자 넷(관계ㆍ성명ㆍ생년월일ㆍ연락처). 미성년이거나 이미 적힌 것이 있을 때만 선다 |
| 위임동의 서명 완료 | 받은 보호자를 거래처에 적는다. **비어 있는 칸만** — 손으로 고쳐 둔 값을 덮지 않는다 |
| 서명 화면 | 거래처에 적힌 보호자를 미리 세운다. 서명은 그래도 다시 받는다 |

**막고 있던 진짜 원인은 따로 있었다** — 거래처에 `is_minor` 가 **아예 없었다.**
「미성년이면 세운다」를 그 값으로 걸어 두었더니 늘 빈 값을 읽어, 만 8세 아이의
거래처에도 칸이 서지 않았다. 생년월일로 세는 자리를 먼저 만들었다.

창을 채우는 값에도 보호자 넷이 빠져 있어, 적어 둔 보호자가 창에 뜨지 않고
그대로 저장하면 지워질 자리였다.

**확인** — 서명 한 번에 거래처로 돌아왔다.

```
guardian_name = '남수현'   guardian_relation = '부'
guardian_birth_date = '1984-07-11'   guardian_phone = '010-8716-0133'
이력: 위임동의에서 받은 보호자를 거래처에 적었습니다 (남수현)
```

두 번째 동의(178)를 열었을 때 보호자 넷이 **미리 채워져** 나왔다. 다시 묻지 않는다.

### 서명란이 둘이던 것 (고침)

요양비위임장에는 서명 자리가 둘이라(위임인ㆍ법정대리인) 화면도 둘을 받았다.
그런데 위임인이 만 여덟 살이면 **그 서명도 결국 보호자가 그린다** — 한 사람이
두 번 그리고, 그중 하나가 아이 것으로 남았다.

미성년이면 위임인 서명란을 세우지 않고, **보호자 서명 하나를 종이의 두 자리에**
찍는다. 서식은 그대로라 공단에 내는 것은 달라지지 않는다.

```
위임인 서명 8874자 / 보호자 서명 8874자 → 같다
```

화면에도 적었다 — 「위임인이 미성년이라 이 서명 하나로 위임장의 위임인ㆍ법정대리인
두 자리를 채웁니다.」 **성년 건은 그대로 서명란 하나다.**

## 새길 것

- **한 값을 두 화면이 각각 세우면 서로 덮는다.** 팝빌 탭에서 고친 테스트 팩스번호가
  조용히 묻혔다 — 저장한 사람은 된 줄 안다. 설정 표(DB)에도 두 벌이 누워 있었다
- **아무 일도 하지 않는 설정은 거짓말을 한다.** 하이팩스ㆍ문자 시뮬레이션ㆍ발신 번호가
  모두 같은 갈래였다. 화면에 있으면 일해야 한다
- **팝빌은 포인트 주머니가 둘이다.** 연동회원(coloplast)에 9,990점이 있어도
  **파트너(LINKTHELAB)** 가 비면 나가지 않는다. 오류 문구가 「파트너」라 적어 준다
- **실패만 남기면 「보냈나?」에 답할 수 없다.** 위드웍스 알림 메일도 성공을 남기게 고쳤다
- **한 줄로 쓴 `@php … @endphp` 는 앞 지시어가 글자로 남는다.** 주석에 지시어 이름을
  적어도 Blade 가 집는다 — 인라인 꼴로 적는다

## 문자ㆍ팩스가 실제로 가는 곳

시험 중에 두 겹으로 막는다. 층이 다르다.

| | 웹 화면 = 테스트 | 문자 발송 = 우리에게만 |
|---|---|---|
| 무엇을 막나 | **적히는 값** — 손으로 치다 틀린 번호가 거래처에 저장되는 것 | **나가는 곳** — 무엇이 적혀 있든 테스트 번호로만 |
| 언제 | 화면을 그릴 때 | 보낼 때 |

**「실제」로 두면 화면에서 고른 번호가 곧 받는 곳이다.** 전화번호 1을
「정희경 · 01087160133」으로 골라 저장하니 그리로 갔다(접수 `026090714000006028`).
웹 화면이 테스트라 그 번호가 우리 사람 것으로만 저장되므로, 실제로 두어도 새지 않는다.

**전화번호 2는 문자에 쓰이지 않는다** — 문자는 모두 거래처의 `mobile`(전화번호 1)만 본다.
