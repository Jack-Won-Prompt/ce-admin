# 기록 규칙 — 파워포인트로 옮길 수 있게

사람마다 `{이름}/기록.md` 하나를 쓴다. **한 걸음이 곧 한 장(슬라이드)**이다.

## 왜 이렇게 적나

이 기록을 읽는 사람은 **그 자리에 없었다.** 화면 이름만 적으면 어느 화면인지
모르고, 값만 적으면 어디에 넣었는지 모르고, 단추 이름만 적으면 그것을 눌러서
무엇이 일어났는지 모른다. **넷을 함께 적어야 한 장이 된다.**

> 화면 → 넣은 값 → 누른 것 → 그래서 무엇이 일어났나

## 한 걸음의 꼴

```markdown
### 3-2 · 상세 목록 › 병원ㆍ처방 정보

**화면** 주문ㆍ재구매 › 주문 등록 › `RX-20260908-001` › 상세 목록 탭 › 병원ㆍ처방 정보
**주소** https://www.ceadmin.co.kr/prescriptions/RX-20260908-001
**캡처** `_화면/김태오/12_상세목록-병원처방정보.png`

**넣은 값**

| 칸 | 넣은 값 | 어디서 왔나 |
|---|---|---|
| 병원명 | 서울가온대학교병원 | 처방전 (띠) · **［병원 조회］로 골랐다** |
| 요양병원 코드 | 1231013 | 병원 조회가 함께 채웠다 |
| 상병코드 | Q05.9 | 처방전 손글씨 |
| 진단 확인일 | 2026-08-20 | **시험값** — 처방전에 없다 |

**누른 것** ［저장］ (`saveOCR()`)

**그 단추가 시키는 일**
`PUT /prescriptions/{rx}/ocr` 로 간다. 처방전 칸을 적고, 그 가운데 사람에 붙는
것(이메일ㆍ전화2ㆍ건보등록 …)은 **거래처로 올려 적는다**. 처음 저장하는 자리가
처방전을 사람에게 붙이는 자리라, 여기서 접수 안내 문자와 위임동의 링크가
함께 나간다(설정에 따라).

**확인**

- [x] 「저장되었습니다」
- [x] 처방전종료일이 **발행일 + 90일**로 저절로 잡힌다 (2026-12-02)
- [ ] ⚠️ 총계가 540인데 표 아래 합계는 0 — → 결함 ①
```

## 다섯 가지를 꼭 적는다

| | 무엇 | 왜 |
|---|---|---|
| **화면** | 메뉴 길 + 탭 + 팝업 이름 | 「주문 등록」만으로는 탭이 넷이라 못 찾는다 |
| **주소** | 그 화면의 URL | 다시 열어 볼 수 있어야 한다 |
| **캡처** | `_화면/{이름}/NN_이름.png` | 슬라이드에 그대로 붙는다 |
| **넣은 값** | 칸 이름 · 값 · **어디서 왔나** | 「시험값」과 「자료에서 온 값」을 갈라야 나중에 믿을 수 있다 |
| **트리거** | 단추가 부르는 것과 **그것이 하는 일** | 이것이 없으면 화면 설명서지 시험 기록이 아니다 |

## 캡처 규칙

- 이름은 `NN_화면이름.png` — **NN 은 걸음 차례**. 슬라이드 순서가 곧 파일 순서다
- **팝업은 따로 찍는다** — 뒤 화면과 함께 찍으면 무엇을 보라는 것인지 흐려진다
- **위드웍스는 `ww_` 를 앞에 붙인다** — `21_ww_판매주문-조회.png`
- **누르기 전과 뒤가 다르면 둘 다** 찍는다(`14a_결제전송-창.png` · `14b_결제전송-결과.png`)
- 결함이 난 자리는 **틀린 값이 보이게** 찍는다. 고친 뒤 화면은 따로 찍어 나란히 둔다

## 트리거를 적는 법

단추 이름만 적지 않는다. **셋을 적는다.**

```
누른 것        ［주문 생성 및 연계］ (`createOrder()`)
어디로 가나    POST /prescriptions/{rx}/withworks-order
무엇이 일어나나 ① 우리 주문(EUD…)을 세우고 ② 위드웍스 so_store 로 보내
               판매주문(S…)을 받아 적는다 ③ 접수 안내와 결제 안내 문자가 나간다
               ④ 보낸 값 그대로가 연계 확인 이메일로도 간다
```

「무엇이 일어나나」는 **눈에 보이지 않는 것까지** 적는다. 화면에 안 보이는 일이
그 단추의 진짜 값어치일 때가 많다(문자ㆍ이메일ㆍ창고 연계ㆍ증빙 발행).

## 파워포인트로 옮기는 차례

1. `기록.md` 의 `###` 하나가 **한 장**
2. 장 제목 = `###` 줄
3. 왼쪽에 **캡처**, 오른쪽에 **넣은 값 표 + 누른 것 + 트리거**
4. 확인 목록은 장 아래 띠로
5. ⚠️ 가 붙은 줄은 **붉게** — 결함 슬라이드는 따로 묶어 뒤에 모은다
