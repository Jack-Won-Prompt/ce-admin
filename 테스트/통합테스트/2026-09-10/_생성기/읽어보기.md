# 시나리오 실행 순서 txt 생성기

CASE 폴더마다 「시나리오 실행 순서 및 세부 내용.txt」를 만든다.

```
php dump.php          # 운영에서 CASE 열일곱 건의 실제 값을 읽어 dump.json 으로
python parse_md.py    # 테스트_시나리오_상세.md 를 절 단위로 쪼개 md.json 으로
python txt_make.py    # 열일곱 건 모두 (인자로 번호를 주면 그 건만)
```

| 파일 | 하는 일 |
|---|---|
| `dump.php` | 거래처ㆍ처방ㆍ주문ㆍ동의ㆍ첨부의 실제 값을 읽는다. 읽기만 한다 |
| `parse_md.py` | 상세.md 의 본문 절 167개와 확인 항목 635개를 뽑는다 (부록은 뺀다) |
| `plan.py` | 마디 스물한 개와, 절을 어느 마디에서 밟을지 적은 배정표ㆍ해당 없음 판정 |
| `steps.py` | 마디마다 화면에 넣을 값ㆍ누를 것ㆍ저절로 일어나는 것ㆍ경고 |
| `txt_make.py` | 위 넷을 합쳐 txt 를 쓴다 |

**빠짐없음은 세어서 확인한다.** `txt_make.py` 가 마지막에 원문 대조표를 붙이고
`밟음 + 해당 없음 = 167` 이 아니면 멈춘다. 상세.md 에 절을 보태면 그 절이
`plan.py` 의 배정표에 없어도 「20 회귀 확인」으로 들어가므로 수는 맞는다 —
제자리에 놓으려면 배정표에 한 줄 보탠다.

값은 모두 운영에서 읽은 것이다. 지어내지 않는다.

## 밟은 자취 — 2026-09-11 확정

```
php confirm_dump.php   # 확정 결과를 confirm.json 으로 (출고번호는 so.confirmed 웹훅에서)
python apply_confirm.py # 폴더마다 기록.md 에 「8 · 위드웍스 확정」 마디를 끼운다
python txt_make.py      # txt 를 다시 쓴다 — confirm.json 이 있으면 마디에 자취가 붙는다
python apply_trace.py   # 바탕화면 갈래별 txt 여덟 개에 자취 토막만 끼운다
```

`apply_confirm.py` 와 `apply_trace.py` 는 **다시 돌려도 두 번 붙지 않는다** —
이미 끼워진 토막을 걷어내고 다시 끼운다.

`apply_trace.py` 가 손대는 파일은 손으로 손본 것이라 **통째로 덮지 않는다.**
마디 [12]~[17] 의 「원문 확인 항목」 앞자리에만 끼우고 나머지는 건드리지 않는다.
