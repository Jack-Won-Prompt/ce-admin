2. 주문 제품
 2.1 주문 생성 및 연계
  2.1.1 위드웍스 판매주문 생성 확인

  2.2.1 상세 목록 링크페이 선택 시 - 주문 제품 등록 후 저장/주문 생성 및 연계 시 주문이 접수 SMS 자동 발송, 주문 결제 금액 SMS 자동 발송(토스페이먼트 결제(카드/가상계좌))
  2.2.2 상세 목록 가상계좌 선택 시 - 주문 제품 등록 후 저장/주문 생성 및 연계 시 주문이 접수 SMS 자동 발송, 주문 결제 금액 SMS 자동 발송(가상계좌 생성 후 생성 정보 고객에 매칭하고 매칭 된 가상계좌번호 전송)

입금
3.입금 확인
 3.1 카드 결제 완료 시 카드 결제 관련 정보 토스페이먼트에서 웹훅으로 모든 정보 받아지는지
  3.1.1 청구 전략 별 결제 서류 및 거래명세서 자동 생성 확인
 3.2 가상계좌 결제 완료 시 가상계좌 토스페이먼트에서 웹훅으로 모든 정보 받아지는지
  3.2.1 청구 전략 별 결제 서류 및 거래명세서 자동 생성 확인
 3.3 토스페이먼츠로 부터 웹훅으로 결제 완료 받으면, 결제 완료와 받음과 동시에 해당 위드웍스의 판매주문 확정 전송

위드웍스
 4.1 CEAdmin으로 웹훅으로 판매주문 확정 전송하면 위드웍스에서 판매주문 확정 시 위드웍스 출고 생성
 4.2 위드웍스 출고 할당 시 CEAdmn 웹훅 상태 값 전송,  CEAdmin은 주문은 할당으로 상태 변경
 4.3 위드웍스 출고 피킹 시 CEAdmn 웹훅 상태 값 전송,  CEAdmin은 주문은 피킹으로 상태 변경
 4.4 위드웍스 출고 송장 생성 시 CEAdmn 웹훅 상태 값 및 송장번호 전송,  CEAdmin은 주문은 송장출력으로 상태 변경
 4.5 위드웍스 출고 완료 시 CEAdmn 웹훅 상태 값 전송 및 CEAdmin에서 출고 완료 값 받는 즉시 배송(송장번호 포함) 시작 SMS 전송,  CEAdmin은 주문은 출고완료으로 상태 변경
 4.6 위드웍스 배송완료(배송완료 송장 업로드 시) CEAdmn 웹훅 상태 값 전송 및 CEAdmin에서배송완료 값 받는 즉시 CEAdmin은 주문은 주문 배송완료 상태 변경
